9۔ مکمل آف لائن سسٹم

تمام دعائیں، ترجمے، حوالے، سرچ انڈیکس اور دیگر ضروری مواد ایپ کے اندر موجود ہو۔

- پسندیدہ دعائیں محفوظ ہوں
- تمام حوالے دکھائی دیں

صرف اس وجہ سے کسی دعا کو لوڈ ہونے میں تاخیر نہ ہو کہ انٹرنیٹ دستیاب نہیں ہے۔

ایپ کے بنیادی استعمال کے لیے کسی سرور، API یا آن لائن اکاؤنٹ کی ضرورت نہ ہو۔

12۔ AdMob Monetization

ایپلیکیشن میں Google AdMob کی سہولت بھی رکھی جائے۔

لیکن اشتہارات کی وجہ سے دینی مواد متاثر نہ ہو۔

شرائط:

- Banner Ads کی جگہ مناسب ہو۔
- دعاؤں کے عربی متن کے اوپر اشتہار نہ آئے۔
- اشتہار کی وجہ سے Copy بٹن متاثر نہ ہو۔
- ہر دعا کے درمیان زبردستی اشتہار نہ دکھایا جائے۔
- Interstitial Ads محدود اور مناسب جگہوں پر ہوں۔
- کسی بھی اشتہار کو دعا یا حدیث کا حصہ ظاہر نہ کیا جائے۔
- اشتہارات بند ہونے کی صورت میں بھی ایپ مکمل کام کرے۔

AdMob App ID اور Ad Unit IDs کے لیے واضح Configuration رکھی جائے۔

ابتدائی ٹیسٹنگ میں صرف Google کے Test Ad IDs استعمال ہوں۔

اصل IDs صرف پروڈکشن ریلیز کے لیے الگ Configuration کے ذریعے شامل ہوں۔

کوئی فرضی AdMob ID نہ بنائی جائے۔

14۔ GitHub کے لیے مکمل ZIP فائل

ZIP کے اندر ایسا مکمل Project Structure ہو جسے GitHub پر اپلوڈ کرکے GitHub Actions کے ذریعے APK اور AAB تیار کیے جا سکیں۔

- package.json، اگر Capacitor استعمال ہو
- capacitor.config.json
- www یا مناسب Web Assets
- Android Project
- Gradle Files
- AndroidManifest.xml
- AdMob Configuration
- Database Files
- App Icons
- Splash Screen Assets
- GitHub Actions Workflow

ضروری فائلیں غائب نہ ہوں۔

ZIP کے اندر ایک غیر ضروری ZIP فائل رکھ کر اصل پروجیکٹ کو اس کے اندر نہ چھپایا جائے۔

GitHub پر اپلوڈ کرنے کے بعد کسی اضافی دستی اصلاح کی ضرورت نہ ہو، سوائے ان معلومات کے جن کے لیے صارف کی اپنی Secret Keys یا IDs درکار ہوں۔

15۔ GitHub Actions کے ذریعے APK اور AAB

GitHub Actions کے لیے مکمل Workflow تیار کیا جائے۔

فائل کا مقام:

.github/workflows/android-build.yml

Workflow میں:

1. Node.js کا موزوں مستحکم ورژن استعمال ہو۔
2. Java کا موزوں مستحکم ورژن استعمال ہو۔
3. ضروری Dependencies انسٹال ہوں۔
4. ZIP یا Source Structure درست طریقے سے تیار ہو۔
5. Capacitor Sync مکمل ہو، اگر Capacitor استعمال کیا گیا ہو۔
6. Android Project درست طریقے سے Build ہو۔
7. Debug APK تیار ہو۔
8. Signed Release APK تیار ہو۔
9. Signed Release AAB تیار ہو۔
10. Build Errors کی واضح رپورٹ ہو۔

GitHub Actions مکمل ہونے کے بعد APK اور AAB کو Artifacts میں دستیاب ہونا چاہیے۔

صارف آسانی سے دونوں فائلیں ڈاؤن لوڈ کر سکے۔

APK فون میں انسٹال اور ٹیسٹنگ کے لیے ہو۔

AAB Google Play Console پر اپلوڈ کرنے کے لیے ہو۔

16۔ Digital Signing اور Keystore

Release APK اور AAB کی مکمل Signing Configuration تیار کی جائے۔

Keystore کے لیے واضح ہدایات دی جائیں۔

GitHub Secrets کے ذریعے درج ذیل معلومات استعمال ہوں:

- KEYSTORE_BASE64
- KEYSTORE_PASSWORD
- KEY_ALIAS
- KEY_PASSWORD

اصل Password یا Keystore کو Source Code میں Hardcode نہ کیا جائے۔

Debug Build اور Release Build کی Signing الگ ہو۔

Release AAB کی Signature Verification لازماً کی جائے۔

ایک ہی ایپ کی آئندہ اپڈیٹس کے لیے Signing Key برقرار رکھنے کی واضح ہدایات دی جائیں۔

17۔ Google Play Store Compliance

ایپلیکیشن کو Google Play Store کی موجودہ پالیسیوں کے مطابق تیار کیا جائے۔

خاص طور پر:

- موجودہ Target API Requirement
- App Bundle Requirements
- Privacy Policy
- Data Safety Form
- Ads Declaration
- Content Rating
- App Access
- Permissions
- App Name
- App Description
- Screenshots
- App Icon
- Release Signing

غیر ضروری Permissions شامل نہ کی جائیں۔

چونکہ ایپ بنیادی طور پر آف لائن ہے، اس لیے غیر ضروری ذاتی معلومات جمع نہ کی جائیں۔

AdMob یا کسی دوسرے SDK کے ذریعے جو معلومات جمع ہوں، ان کی درست وضاحت Privacy Policy اور Data Safety میں ہو۔

Privacy Policy فرضی نہ ہو۔ اصل ایپ کے ڈیٹا استعمال کے مطابق تیار کی جائے۔

Google Play کی موجودہ پالیسیوں کو سرکاری دستاویزات سے Build کے وقت چیک کیا جائے۔ پرانی Target API یا پرانی Gradle Configuration کو بلا تحقیق استعمال نہ کیا جائے۔

18۔ معیار کی جانچ اور مکمل Testing

ایپ مکمل ہونے کے بعد درج ذیل تمام ٹیسٹ کیے جائیں:

- ایپ پہلی مرتبہ درست کھلتی ہے یا نہیں۔
- تمام صفحات درست کام کرتے ہیں یا نہیں۔
- تمام عربی متون درست ہیں یا نہیں۔
- اردو ترجمہ درست RTL میں ہے یا نہیں۔
- تمام دعاؤں کے حوالے موجود ہیں یا نہیں۔
- کاپی بٹن کام کرتا ہے یا نہیں۔
- شیئر بٹن کام کرتا ہے یا نہیں۔
- سرچ کام کرتی ہے یا نہیں۔
- پسندیدہ دعائیں محفوظ ہوتی ہیں یا نہیں۔
- ایپ انٹرنیٹ بند کرکے کام کرتی ہے یا نہیں۔
- ایپ دوبارہ کھولنے پر محفوظ معلومات برقرار رہتی ہیں یا نہیں۔
- تمام بٹن فعال ہیں یا نہیں۔
- کوئی صفحہ خالی یا نامکمل نہیں۔
- AdMob Test Ads درست کام کرتے ہیں یا نہیں۔
- Release APK اور AAB درست Build ہوتے ہیں یا نہیں۔
- Release Signature درست ہے یا نہیں۔

کوئی فرضی Testing Report نہ بنائی جائے۔

جو ٹیسٹ حقیقتاً کیے گئے ہوں صرف انہی کے نتائج پیش کیے جائیں۔

19۔ علمی مواد کی تصدیق اور تحقیقی معیار

یہ پروجیکٹ دینی نوعیت کا ہے، اس لیے علمی صحت کو ظاہری خوبصورتی اور تعداد سے زیادہ اہمیت دی جائے۔

ہر دعا کے لیے ایک منفرد ID ہو۔

ہر حدیث کے ساتھ اس کا اصل ماخذ اور صحت کی تحقیق محفوظ ہو۔

ایک ہی دعا مختلف کتابوں میں متعدد مرتبہ موجود ہو تو اسے غیر ضروری طور پر بار بار نہ دہرایا جائے، البتہ مختلف الفاظ یا مختلف مواقع کی روایات کو الگ شناخت کے ساتھ رکھا جائے۔

قرآنی آیات کا متن مستند مصحف سے لیا جائے۔

عربی متن میں اعراب کی غلطی نہ ہو۔

اردو ترجمہ سلیس اور درست ہو۔

کسی دعا کی فضیلت کے بارے میں ایسی بات نہ لکھی جائے جس کی معتبر دلیل موجود نہ ہو۔

اگر Claude کے پاس کسی حدیث کی مکمل تحقیق یا مستند متن دستیاب نہ ہو تو خود سے مواد مکمل نہ کرے۔ اسے واضح طور پر Pending Verification میں رکھے۔

ایک الگ تحقیقی فائل بھی تیار کرے جس میں تمام دعاؤں کی فہرست، مصادر، حدیث نمبر، درجۂ صحت اور تحقیق کی حالت درج ہو، تاکہ مؤلف یا علمی نگران اس کا جائزہ لے سکیں۔

8۔ اللہ کے خوف، یقین اور دینی سلامتی کی جامع دعا
اللَّهُمَّ اقْسِمْ لَنَا مِنْ خَشْيَتِكَ مَا تَحُولُ بِهِ بَيْنَنَا وَبَيْنَ مَعَاصِيكَ، وَمِنْ طَاعَتِكَ مَا تُبَلِّغُنَا بِهِ جَنَّتَكَ، وَمِنَ الْيَقِينِ مَا تُهَوِّنُ بِهِ عَلَيْنَا مَصَائِبَ الدُّنْيَا، وَمَتِّعْنَا بِأَسْمَاعِنَا وَأَبْصَارِنَا وَقُوَّتِنَا مَا أَحْيَيْتَنَا، وَاجْعَلْهُ الْوَارِثَ مِنَّا، وَاجْعَلْ ثَأْرَنَا عَلَى مَنْ ظَلَمَنَا، وَانْصُرْنَا عَلَى مَنْ عَادَانَا، وَلَا تَجْعَلْ مُصِيبَتَنَا فِي دِينِنَا، وَلَا تَجْعَلِ الدُّنْيَا أَكْبَرَ هَمِّنَا وَلَا مَبْلَغَ عِلْمِنَا، وَلَا تُسَلِّطْ عَلَيْنَا مَنْ لَا يَرْحَمُنَا
ترجمہ: اے اللہ! ہمیں اپنا اتنا خوف عطا فرما جو ہمارے اور ہمارے گناہوں کے درمیان رکاوٹ بن جائے، اتنی فرماں برداری دے جو ہمیں تیری جنت تک پہنچا دے، اور ایسا یقین دے جس سے دنیا کی مصیبتیں ہم پر آسان ہو جائیں۔ جب تک زندہ رکھے ہمیں کان، آنکھوں اور طاقت سے فائدہ دیتا رہ، اور انہیں آخر تک ہمارے ساتھ باقی رکھ۔ جس نے ہم پر ظلم کیا اس سے بدلہ (انصاف کے ساتھ) دلا، ہمارے دشمنوں کے مقابلے میں ہماری مدد فرما، ہماری مصیبت ہمارے دین میں نہ ڈال، دنیا کو ہماری سب سے بڑی فکر اور ہمارے علم کی انتہا نہ بنا، اور ہم پر ایسے شخص کو مسلط نہ کر جو ہم پر رحم نہ کرے۔
حوالہ: سنن ترمذی 3502
9۔ نور کی دعا
اللَّهُمَّ اجْعَلْ فِي قَلْبِي نُورًا، وَفِي لِسَانِي نُورًا، وَاجْعَلْ فِي سَمْعِي نُورًا، وَاجْعَلْ فِي بَصَرِي نُورًا، وَاجْعَلْ مِنْ خَلْفِي نُورًا، وَمِنْ أَمَامِي نُورًا، وَاجْعَلْ مِنْ فَوْقِي نُورًا، وَمِنْ تَحْتِي نُورًا، اللَّهُمَّ أَعْطِنِي نُورًا
ترجمہ: اے اللہ! میرے دل میں نور رکھ دے، میری زبان میں نور، میرے کانوں میں نور اور میری آنکھوں میں نور رکھ دے۔ میرے پیچھے اور میرے آگے نور کر دے، میرے اوپر اور میرے نیچے نور کر دے۔ اے اللہ! مجھے (کامل) نور عطا فرما۔
حوالہ: صحیح مسلم 763 (اصل واقعہ: صحیح بخاری 6316)
10۔ حسنِ اخلاق کی دعا
اللَّهُمَّ كَمَا حَسَّنْتَ خَلْقِي فَحَسِّنْ خُلُقِي
ترجمہ: اے اللہ! جس طرح تو نے میری صورت اچھی بنائی ہے، اسی طرح میرے اخلاق بھی اچھے بنا دے۔
حوالہ: مسند احمد 3823؛ ارواء الغلیل 74 (صحیح)
11۔ بہترین اخلاق کی ہدایت اور بُرے اخلاق سے حفاظت
وَاهْدِنِي لِأَحْسَنِ الْأَخْلَاقِ لَا يَهْدِي لِأَحْسَنِهَا إِلَّا أَنْتَ، وَاصْرِفْ عَنِّي سَيِّئَهَا لَا يَصْرِفُ عَنِّي سَيِّئَهَا إِلَّا أَنْتَ
ترجمہ: اور مجھے سب سے اچھے اخلاق کی ہدایت دے، تیرے سوا کوئی اچھے اخلاق کی ہدایت نہیں دے سکتا۔ اور مجھ سے بُرے اخلاق دور کر دے، تیرے سوا کوئی بُرے اخلاق دور نہیں کر سکتا۔
حوالہ: صحیح مسلم 771 (نماز کی ابتدائی دعا کا حصہ)
12۔ اسمِ اعظم کے وسیلے سے دعا (توحید کے ساتھ)
اللَّهُمَّ إِنِّي أَسْأَلُكَ بِأَنِّي أَشْهَدُ أَنَّكَ أَنْتَ اللَّهُ لَا إِلَهَ إِلَّا أَنْتَ، الْأَحَدُ الصَّمَدُ، الَّذِي لَمْ يَلِدْ وَلَمْ يُولَدْ، وَلَمْ يَكُنْ لَهُ كُفُوًا أَحَدٌ
ترجمہ: اے اللہ! میں تجھ سے مانگتا ہوں اس گواہی کے ساتھ کہ تو ہی اللہ ہے، تیرے سوا کوئی معبود نہیں، تو اکیلا اور بے نیاز ہے، نہ اس کی کوئی اولاد ہے نہ وہ کسی کی اولاد ہے، اور کوئی اس کے برابر نہیں۔
حوالہ: سنن ابو داود 1493، سنن ترمذی 3475، سنن ابن ماجہ 3857
13۔ اسمِ اعظم کے ساتھ حمد و ثنا والی دعا
اللَّهُمَّ إِنِّي أَسْأَلُكَ بِأَنَّ لَكَ الْحَمْدَ، لَا إِلَهَ إِلَّا أَنْتَ، وَحْدَكَ لَا شَرِيكَ لَكَ، الْمَنَّانُ، يَا بَدِيعَ السَّمَاوَاتِ وَالْأَرْضِ، يَا ذَا الْجَلَالِ وَالْإِكْرَامِ، يَا حَيُّ يَا قَيُّومُ، إِنِّي أَسْأَلُكَ
ترجمہ: اے اللہ! میں تجھ سے مانگتا ہوں کیونکہ ہر تعریف تیرے ہی لیے ہے، تیرے سوا کوئی معبود نہیں، تو اکیلا ہے، تیرا کوئی شریک نہیں، تو بہت احسان کرنے والا ہے، آسمانوں اور زمین کو بغیر نمونے کے بنانے والا، عظمت اور بزرگی والا، زندہ اور سب کو سنبھالنے والا ہے۔ (پھر اپنی حاجت مانگے۔)
حوالہ: سنن ابو داود 1495، سنن ترمذی 3544، سنن نسائی 1300، سنن ابن ماجہ 3858
14۔ پریشانی اور بے چینی کی دعا
اللَّهُمَّ رَحْمَتَكَ أَرْجُو فَلَا تَكِلْنِي إِلَى نَفْسِي طَرْفَةَ عَيْنٍ، وَأَصْلِحْ لِي شَأْنِي كُلَّهُ، لَا إِلَهَ إِلَّا أَنْتَ
ترجمہ: اے اللہ! میں تیری رحمت کی امید رکھتا ہوں، پس مجھے پلک جھپکنے کے برابر بھی میرے نفس کے حوالے نہ کر، میرے سارے کام سنوار دے، تیرے سوا کوئی معبود نہیں۔
حوالہ: سنن ابو داود 5090
15۔ بھوک اور خیانت سے پناہ
اللَّهُمَّ إِنِّي أَعُوذُ بِكَ مِنَ الْجُوعِ فَإِنَّهُ بِئْسَ الضَّجِيعُ، وَأَعُوذُ بِكَ مِنَ الْخِيَانَةِ فَإِنَّهَا بِئْسَتِ الْبِطَانَةُ
ترجمہ: اے اللہ! میں بھوک سے تیری پناہ مانگتا ہوں کیونکہ وہ بہت بُرا ساتھی ہے، اور خیانت سے تیری پناہ مانگتا ہوں کیونکہ وہ بہت بُرا رازدار ہے۔
حوالہ: سنن ابو داود 1547، سنن نسائی 5468، سنن ابن ماجہ 3354
16۔ جھگڑے، نفاق اور بداخلاقی سے پناہ
اللَّهُمَّ إِنِّي أَعُوذُ بِكَ مِنَ الشِّقَاقِ وَالنِّفَاقِ وَسُوءِ الْأَخْلَاقِ
ترجمہ: اے اللہ! میں تجھ سے باہمی جھگڑے، نفاق اور بُرے اخلاق سے پناہ مانگتا ہوں۔
حوالہ: سنن ابو داود 1546، سنن نسائی 5486
17۔ نفع بخش علم، پاکیزہ رزق اور مقبول عمل کی دعا (فجر کے بعد)
اللَّهُمَّ إِنِّي أَسْأَلُكَ عِلْمًا نَافِعًا، وَرِزْقًا طَيِّبًا، وَعَمَلًا مُتَقَبَّلًا
ترجمہ: اے اللہ! میں تجھ سے نفع دینے والا علم، پاکیزہ (حلال) رزق اور قبول ہونے والا عمل مانگتا ہوں۔
حوالہ: سنن ابن ماجہ 925
18۔ علم میں نفع اور اضافے کی دعا
اللَّهُمَّ انْفَعْنِي بِمَا عَلَّمْتَنِي، وَعَلِّمْنِي مَا يَنْفَعُنِي، وَزِدْنِي عِلْمًا
ترجمہ: اے اللہ! جو تو نے مجھے سکھایا اس سے مجھے نفع دے، مجھے وہ سکھا جو میرے لیے فائدہ مند ہو، اور میرے علم میں اضافہ فرما۔
حوالہ: سنن ترمذی 3599، سنن ابن ماجہ 251
19۔ حلال رزق اور قرض سے نجات کی دعا
اللَّهُمَّ اكْفِنِي بِحَلَالِكَ عَنْ حَرَامِكَ، وَأَغْنِنِي بِفَضْلِكَ عَمَّنْ سِوَاكَ
ترجمہ: اے اللہ! مجھے حلال دے کر حرام سے بچا لے، اور اپنے فضل سے اپنے سوا سب سے بے نیاز کر دے۔
حوالہ: سنن ترمذی 3563
20۔ مشکل کام آسان ہونے کی دعا
اللَّهُمَّ لَا سَهْلَ إِلَّا مَا جَعَلْتَهُ سَهْلًا، وَأَنْتَ تَجْعَلُ الْحَزْنَ إِذَا شِئْتَ سَهْلًا
ترجمہ: اے اللہ! آسان وہی ہے جسے تو آسان کر دے، اور تو چاہے تو مشکل کو بھی آسان بنا دیتا ہے۔
حوالہ: صحیح ابن حبان 974
21۔ نیکیوں کی توفیق اور اللہ کی محبت کی دعا
اللَّهُمَّ إِنِّي أَسْأَلُكَ فِعْلَ الْخَيْرَاتِ، وَتَرْكَ الْمُنْكَرَاتِ، وَحُبَّ الْمَسَاكِينِ، وَأَنْ تَغْفِرَ لِي وَتَرْحَمَنِي، وَإِذَا أَرَدْتَ فِتْنَةً فِي قَوْمٍ فَتَوَفَّنِي غَيْرَ مَفْتُونٍ، وَأَسْأَلُكَ حُبَّكَ، وَحُبَّ مَنْ يُحِبُّكَ، وَحُبَّ عَمَلٍ يُقَرِّبُ إِلَى حُبِّكَ
ترجمہ: اے اللہ! میں تجھ سے نیک کام کرنے، برے کام چھوڑنے اور مسکینوں سے محبت کی توفیق مانگتا ہوں، اور یہ کہ تو مجھے بخش دے اور مجھ پر رحم فرما۔ جب تو کسی قوم کو آزمائش میں ڈالنا چاہے تو مجھے آزمائش میں پڑے بغیر اٹھا لینا۔ میں تجھ سے تیری محبت، تجھ سے محبت کرنے والوں کی محبت، اور ایسے عمل کی محبت مانگتا ہوں جو مجھے تیری محبت کے قریب کر دے۔
حوالہ: سنن ترمذی 3235
22۔ جان بوجھ کر اور انجانے میں شرک سے حفاظت
اللَّهُمَّ إِنِّي أَعُوذُ بِكَ أَنْ أُشْرِكَ بِكَ وَأَنَا أَعْلَمُ، وَأَسْتَغْفِرُكَ لِمَا لَا أَعْلَمُ
ترجمہ: اے اللہ! میں اس بات سے تیری پناہ مانگتا ہوں کہ جانتے ہوئے تیرے ساتھ شرک کروں، اور جس (شرک) کو میں نہیں جانتا اس کی تجھ سے معافی مانگتا ہوں۔
حوالہ: الادب المفرد 716؛ مسند احمد (صحیح)
23۔ بُرے اخلاق، اعمال اور خواہشات سے پناہ
اللَّهُمَّ إِنِّي أَعُوذُ بِكَ مِنْ مُنْكَرَاتِ الْأَخْلَاقِ وَالْأَعْمَالِ وَالْأَهْوَاءِ
ترجمہ: اے اللہ! میں بُرے اخلاق، بُرے اعمال اور بُری خواہشات سے تیری پناہ مانگتا ہوں۔
حوالہ: سنن ترمذی 3591
24۔ برص، جنون، جذام اور بُری بیماریوں سے پناہ
اللَّهُمَّ إِنِّي أَعُوذُ بِكَ مِنَ الْبَرَصِ وَالْجُنُونِ وَالْجُذَامِ وَمِنْ سَيِّئِ الْأَسْقَامِ
ترجمہ: اے اللہ! میں برص، پاگل پن، کوڑھ اور بُری بیماریوں سے تیری پناہ مانگتا ہوں۔
حوالہ: سنن ابو داود 1554، سنن نسائی 5493
25۔ جسم، سماعت اور بصارت کی عافیت کی دعا
اللَّهُمَّ عَافِنِي فِي بَدَنِي، اللَّهُمَّ عَافِنِي فِي سَمْعِي، اللَّهُمَّ عَافِنِي فِي بَصَرِي، لَا إِلَهَ إِلَّا أَنْتَ
ترجمہ: اے اللہ! میرے بدن کو عافیت دے، میرے کانوں کو عافیت دے، میری آنکھوں کو عافیت دے، تیرے سوا کوئی معبود نہیں۔
حوالہ: سنن ابو داود، کتاب الادب، باب ما یقول اذا اصبح (حدیث ابو بکرہ رضی اللہ عنہ)
26۔ دین، دنیا، گھر اور مال کی عافیت، اور پردہ پوشی کی دعا
اللَّهُمَّ إِنِّي أَسْأَلُكَ الْعَفْوَ وَالْعَافِيَةَ فِي دِينِي وَدُنْيَايَ وَأَهْلِي وَمَالِي، اللَّهُمَّ اسْتُرْ عَوْرَاتِي وَآمِنْ رَوْعَاتِي
ترجمہ: اے اللہ! میں تجھ سے اپنے دین، دنیا، گھر والوں اور مال میں معافی اور عافیت مانگتا ہوں۔ اے اللہ! میرے عیبوں پر پردہ ڈال دے اور میری گھبراہٹوں کو امن میں بدل دے۔
حوالہ: سنن ابو داود 5074، سنن ابن ماجہ 3871
27۔ زندگی اور موت میں بہتر فیصلے کی دعا
اللَّهُمَّ بِعِلْمِكَ الْغَيْبَ وَقُدْرَتِكَ عَلَى الْخَلْقِ، أَحْيِنِي مَا عَلِمْتَ الْحَيَاةَ خَيْرًا لِي، وَتَوَفَّنِي إِذَا عَلِمْتَ الْوَفَاةَ خَيْرًا لِي
ترجمہ: اے اللہ! اپنے علمِ غیب اور مخلوق پر اپنی قدرت کے واسطے سے، مجھے اس وقت تک زندہ رکھ جب تک زندگی میرے لیے بہتر ہو، اور مجھے اس وقت وفات دے جب موت میرے لیے بہتر ہو۔
حوالہ: سنن نسائی 1305؛ مسند احمد (صحیح)
28۔ دین کے کام میں ثابت قدمی اور شکر کی توفیق
اللَّهُمَّ إِنِّي أَسْأَلُكَ الثَّبَاتَ فِي الْأَمْرِ، وَالْعَزِيمَةَ عَلَى الرُّشْدِ، وَأَسْأَلُكَ شُكْرَ نِعْمَتِكَ، وَحُسْنَ عِبَادَتِكَ
ترجمہ: اے اللہ! میں تجھ سے (دین کے) کام میں ثابت قدمی اور ہدایت کے راستے پر پختہ ارادہ مانگتا ہوں، اور تیری نعمت کا شکر اور اچھے طریقے سے تیری عبادت کی توفیق مانگتا ہوں۔
حوالہ: مسند احمد؛ السلسلہ الصحیحہ (البانی: صحیح)
29۔ ذکر، شکر اور اچھی عبادت میں مدد کی دعا
اللَّهُمَّ أَعِنِّي عَلَى ذِكْرِكَ وَشُكْرِكَ وَحُسْنِ عِبَادَتِكَ
ترجمہ: اے اللہ! اپنے ذکر، اپنے شکر اور اچھے انداز میں اپنی عبادت کرنے میں میری مدد فرما۔
حوالہ: سنن ابو داود 1522، سنن نسائی 1303
30۔ اختلاف کے وقت حق کی طرف رہنمائی کی دعا
اللَّهُمَّ رَبَّ جِبْرَائِيلَ وَمِيكَائِيلَ وَإِسْرَافِيلَ، فَاطِرَ السَّمَاوَاتِ وَالْأَرْضِ، عَالِمَ الْغَيْبِ وَالشَّهَادَةِ، أَنْتَ تَحْكُمُ بَيْنَ عِبَادِكَ فِيمَا كَانُوا فِيهِ يَخْتَلِفُونَ، اهْدِنِي لِمَا اخْتُلِفَ فِيهِ مِنَ الْحَقِّ بِإِذْنِكَ، إِنَّكَ تَهْدِي مَنْ تَشَاءُ إِلَى صِرَاطٍ مُسْتَقِيمٍ
ترجمہ: اے اللہ! جبرائیل، میکائیل اور اسرافیل کے رب، آسمانوں اور زمین کے پیدا کرنے والے، غیب و ظاہر کے جاننے والے! تو ہی اپنے بندوں کے درمیان ان باتوں کا فیصلہ کرے گا جن میں وہ اختلاف کرتے ہیں۔ جن باتوں میں اختلاف ہوا ان میں اپنے حکم سے مجھے حق کی راہ دکھا دے، بے شک تو جسے چاہے سیدھے راستے کی ہدایت دیتا ہے۔
حوالہ: صحیح مسلم 770
حصہ دوم (31 تا 60)
31۔ دونوں سجدوں کے درمیان کی دعا
رَبِّ اغْفِرْ لِي وَارْحَمْنِي وَاجْبُرْنِي وَارْفَعْنِي وَارْزُقْنِي وَاهْدِنِي
ترجمہ: اے میرے رب! مجھے بخش دے، مجھ پر رحم فرما، میری کمی پوری فرما دے، مجھے بلند مرتبہ دے، مجھے رزق عطا کر اور مجھے ہدایت دے۔
حوالہ: سنن ابو داود 850، سنن ترمذی 284
32۔ رکوع و سجدے میں فرشتوں اور جبریل کے رب کی پاکی
سُبُّوحٌ قُدُّوسٌ رَبُّ الْمَلَائِكَةِ وَالرُّوحِ
ترجمہ: (اللہ) نہایت پاک اور نہایت مقدس ہے، فرشتوں اور جبریل کا رب ہے۔
حوالہ: صحیح مسلم 487
33۔ رکوع و سجدے میں تسبیح کے ساتھ مغفرت کی دعا
سُبْحَانَكَ اللَّهُمَّ رَبَّنَا وَبِحَمْدِكَ، اللَّهُمَّ اغْفِرْ لِي
ترجمہ: اے اللہ! اے ہمارے رب! تو پاک ہے اور اپنی تعریف کے ساتھ ہے، اے اللہ! مجھے بخش دے۔
حوالہ: صحیح بخاری 817، صحیح مسلم 484
34۔ سجدے میں اللہ کی رضا کے وسیلے سے پناہ
اللَّهُمَّ إِنِّي أَعُوذُ بِرِضَاكَ مِنْ سَخَطِكَ، وَبِمُعَافَاتِكَ مِنْ عُقُوبَتِكَ، وَأَعُوذُ بِكَ مِنْكَ، لَا أُحْصِي ثَنَاءً عَلَيْكَ، أَنْتَ كَمَا أَثْنَيْتَ عَلَى نَفْسِكَ
ترجمہ: اے اللہ! میں تیری رضا کے ذریعے تیری ناراضی سے، تیری معافی کے ذریعے تیری سزا سے، اور خود تجھ ہی سے تیری پناہ مانگتا ہوں۔ میں تیری تعریف شمار نہیں کر سکتا، تو ویسا ہی ہے جیسی تو نے خود اپنی تعریف کی۔
حوالہ: صحیح مسلم 486
35۔ گناہوں سے مکمل پاکی کی دعا
اللَّهُمَّ اغْسِلْ خَطَايَايَ بِمَاءِ الثَّلْجِ وَالْبَرَدِ، وَنَقِّ قَلْبِي مِنَ الْخَطَايَا كَمَا نَقَّيْتَ الثَّوْبَ الْأَبْيَضَ مِنَ الدَّنَسِ، وَبَاعِدْ بَيْنِي وَبَيْنَ خَطَايَايَ كَمَا بَاعَدْتَ بَيْنَ الْمَشْرِقِ وَالْمَغْرِبِ
ترجمہ: اے اللہ! میرے گناہ برف اور اولے کے پانی سے دھو دے، میرے دل کو گناہوں سے ایسے صاف کر دے جیسے سفید کپڑا میل سے صاف کیا جاتا ہے، اور مجھ میں اور میرے گناہوں میں اتنی دوری کر دے جتنی مشرق اور مغرب میں ہے۔
حوالہ: صحیح بخاری 744، صحیح مسلم 598
36۔ تہجد کی جامع دعا (حمد، ایمان اور توکل)
اللَّهُمَّ لَكَ الْحَمْدُ، أَنْتَ قَيِّمُ السَّمَاوَاتِ وَالْأَرْضِ وَمَنْ فِيهِنَّ، وَلَكَ الْحَمْدُ، أَنْتَ نُورُ السَّمَاوَاتِ وَالْأَرْضِ، وَلَكَ الْحَمْدُ، أَنْتَ رَبُّ السَّمَاوَاتِ وَالْأَرْضِ وَمَنْ فِيهِنَّ، أَنْتَ الْحَقُّ، وَوَعْدُكَ الْحَقُّ، وَلِقَاؤُكَ حَقٌّ، وَقَوْلُكَ حَقٌّ، وَالْجَنَّةُ حَقٌّ، وَالنَّارُ حَقٌّ، وَالسَّاعَةُ حَقٌّ، اللَّهُمَّ لَكَ أَسْلَمْتُ، وَبِكَ آمَنْتُ، وَعَلَيْكَ تَوَكَّلْتُ، وَإِلَيْكَ أَنَبْتُ، وَبِكَ خَاصَمْتُ، وَإِلَيْكَ حَاكَمْتُ، فَاغْفِرْ لِي مَا قَدَّمْتُ وَمَا أَخَّرْتُ، وَمَا أَسْرَرْتُ وَمَا أَعْلَنْتُ، أَنْتَ إِلَهِي لَا إِلَهَ إِلَّا أَنْتَ
ترجمہ: اے اللہ! سب تعریف تیرے ہی لیے ہے، تو آسمانوں اور زمین کو اور ان میں موجود سب کو قائم رکھنے والا ہے، تو ان کا نور ہے اور ان کا رب ہے۔ تو حق ہے، تیرا وعدہ حق ہے، تجھ سے ملاقات حق ہے، تیرا فرمان حق ہے، جنت حق ہے، جہنم حق ہے اور قیامت حق ہے۔ اے اللہ! میں تیرا فرماں بردار ہوا، تجھ پر ایمان لایا، تجھ پر بھروسا کیا، تیری طرف رجوع کیا، تیری مدد سے (دشمنوں سے) جھگڑا کیا اور تیرے ہی پاس فیصلہ لایا۔ پس میرے اگلے پچھلے اور چھپے ظاہر گناہ بخش دے، تو ہی میرا معبود ہے، تیرے سوا کوئی معبود نہیں۔
حوالہ: صحیح بخاری 1120 (اور صحیح مسلم 769)
37۔ تشہد کے بعد جنت مانگنے اور جہنم سے پناہ کی دعا
اللَّهُمَّ إِنِّي أَسْأَلُكَ الْجَنَّةَ وَأَعُوذُ بِكَ مِنَ النَّارِ
ترجمہ: اے اللہ! میں تجھ سے جنت مانگتا ہوں اور جہنم سے تیری پناہ چاہتا ہوں۔
حوالہ: سنن ابو داود 792
38۔ جنت اور اس کے قریب کرنے والے اعمال کی دعا
اللَّهُمَّ إِنِّي أَسْأَلُكَ الْجَنَّةَ وَمَا قَرَّبَ إِلَيْهَا مِنْ قَوْلٍ أَوْ عَمَلٍ، وَأَعُوذُ بِكَ مِنَ النَّارِ وَمَا قَرَّبَ إِلَيْهَا مِنْ قَوْلٍ أَوْ عَمَلٍ
ترجمہ: اے اللہ! میں تجھ سے جنت مانگتا ہوں اور ہر اس قول و عمل کی توفیق جو جنت کے قریب کرے، اور جہنم سے اور ہر اس قول و عمل سے تیری پناہ مانگتا ہوں جو جہنم کے قریب کرے۔
حوالہ: سنن ابن ماجہ 3846 (ایک طویل دعا کا حصہ)
39۔ مسجد سے نکلتے وقت اللہ کے فضل کی دعا
اللَّهُمَّ إِنِّي أَسْأَلُكَ مِنْ فَضْلِكَ
ترجمہ: اے اللہ! میں تجھ سے تیرا فضل مانگتا ہوں۔
حوالہ: صحیح مسلم 713
40۔ گھر سے نکلتے وقت توکل کی دعا
بِسْمِ اللَّهِ، تَوَكَّلْتُ عَلَى اللَّهِ، وَلَا حَوْلَ وَلَا قُوَّةَ إِلَّا بِاللَّهِ
ترجمہ: اللہ کے نام سے، میں نے اللہ پر بھروسا کیا، اور گناہ سے بچنے کی طاقت اور نیکی کی قوت صرف اللہ کی مدد سے ہے۔
حوالہ: سنن ابو داود 5095، سنن ترمذی 3426
41۔ گمراہی، لغزش، ظلم اور جہالت سے پناہ
اللَّهُمَّ إِنِّي أَعُوذُ بِكَ أَنْ أَضِلَّ أَوْ أُضَلَّ، أَوْ أَزِلَّ أَوْ أُزَلَّ، أَوْ أَظْلِمَ أَوْ أُظْلَمَ، أَوْ أَجْهَلَ أَوْ يُجْهَلَ عَلَيَّ
ترجمہ: اے اللہ! میں تیری پناہ مانگتا ہوں اس سے کہ میں خود گمراہ ہوں یا کوئی مجھے گمراہ کرے، میں پھسلوں یا مجھے پھسلایا جائے، میں ظلم کروں یا مجھ پر ظلم ہو، میں جہالت کروں یا مجھ سے جہالت برتی جائے۔
حوالہ: سنن ابو داود 5094، سنن ترمذی 3427، سنن ابن ماجہ 3884
42۔ سونے سے پہلے قرض ادا ہونے اور محتاجی دور ہونے کی دعا
اللَّهُمَّ رَبَّ السَّمَاوَاتِ السَّبْعِ وَرَبَّ الْعَرْشِ الْعَظِيمِ، رَبَّنَا وَرَبَّ كُلِّ شَيْءٍ، فَالِقَ الْحَبِّ وَالنَّوَى، وَمُنْزِلَ التَّوْرَاةِ وَالْإِنْجِيلِ وَالْفُرْقَانِ، أَعُوذُ بِكَ مِنْ شَرِّ كُلِّ شَيْءٍ أَنْتَ آخِذٌ بِنَاصِيَتِهِ، اللَّهُمَّ أَنْتَ الْأَوَّلُ فَلَيْسَ قَبْلَكَ شَيْءٌ، وَأَنْتَ الْآخِرُ فَلَيْسَ بَعْدَكَ شَيْءٌ، وَأَنْتَ الظَّاهِرُ فَلَيْسَ فَوْقَكَ شَيْءٌ، وَأَنْتَ الْبَاطِنُ فَلَيْسَ دُونَكَ شَيْءٌ، اقْضِ عَنَّا الدَّيْنَ وَأَغْنِنَا مِنَ الْفَقْرِ
ترجمہ: اے اللہ! سات آسمانوں اور عرشِ عظیم کے رب، ہمارے اور ہر چیز کے رب، دانے اور گٹھلی کو پھاڑنے والے، تورات، انجیل اور قرآن اتارنے والے! میں ہر اس چیز کے شر سے تیری پناہ مانگتا ہوں جس کی پیشانی تیرے قبضے میں ہے۔ اے اللہ! تو ہی سب سے پہلے ہے، تجھ سے پہلے کچھ نہیں؛ تو ہی سب کے بعد ہے، تیرے بعد کچھ نہیں؛ تو ہی سب سے اوپر ہے، تجھ سے اوپر کچھ نہیں؛ تو ہی سب سے قریب ہے، تجھ سے قریب کچھ نہیں۔ ہمارا قرض ادا کروا دے اور ہمیں محتاجی سے بے نیاز کر دے۔
حوالہ: صحیح مسلم 2713
43۔ ناگہانی اور بُری موتوں سے پناہ
اللَّهُمَّ إِنِّي أَعُوذُ بِكَ مِنَ التَّرَدِّي وَالْهَدْمِ وَالْغَرَقِ وَالْحَرِيقِ، وَأَعُوذُ بِكَ أَنْ يَتَخَبَّطَنِي الشَّيْطَانُ عِنْدَ الْمَوْتِ، وَأَعُوذُ بِكَ أَنْ أَمُوتَ فِي سَبِيلِكَ مُدْبِرًا، وَأَعُوذُ بِكَ أَنْ أَمُوتَ لَدِيغًا
ترجمہ: اے اللہ! میں بلندی سے گرنے، دیوار وغیرہ کے نیچے دبنے، ڈوبنے اور جلنے سے تیری پناہ مانگتا ہوں۔ موت کے وقت شیطان کے مجھے بہکانے سے، تیری راہ میں پیٹھ پھیر کر مرنے سے، اور زہریلے ڈنک سے مرنے سے بھی تیری پناہ مانگتا ہوں۔
حوالہ: سنن ابو داود 1552، سنن نسائی 5531
44۔ وضو کے بعد توبہ کرنے والوں اور پاک رہنے والوں میں شمولیت کی دعا
اللَّهُمَّ اجْعَلْنِي مِنَ التَّوَّابِينَ وَاجْعَلْنِي مِنَ الْمُتَطَهِّرِينَ
ترجمہ: اے اللہ! مجھے بہت توبہ کرنے والوں میں شامل فرما اور مجھے خوب پاک رہنے والوں میں شامل فرما۔
حوالہ: سنن ترمذی 55
45۔ وضو کے بعد توبہ و استغفار کی دعا
سُبْحَانَكَ اللَّهُمَّ وَبِحَمْدِكَ، أَشْهَدُ أَنْ لَا إِلَهَ إِلَّا أَنْتَ، أَسْتَغْفِرُكَ وَأَتُوبُ إِلَيْكَ
ترجمہ: اے اللہ! تو پاک ہے اور اپنی تعریف کے ساتھ ہے، میں گواہی دیتا ہوں کہ تیرے سوا کوئی معبود نہیں، میں تجھ سے بخشش مانگتا ہوں اور تیری طرف توبہ کرتا ہوں۔
حوالہ: عمل الیوم واللیلۃ للنسائی 81؛ ارواء الغلیل 969 (صحیح)
46۔ میزبان کے لیے برکت و مغفرت کی دعا
اللَّهُمَّ بَارِكْ لَهُمْ فِيمَا رَزَقْتَهُمْ، وَاغْفِرْ لَهُمْ وَارْحَمْهُمْ
ترجمہ: اے اللہ! جو رزق تو نے ان کو دیا اس میں برکت دے، ان کو بخش دے اور ان پر رحم فرما۔
حوالہ: صحیح مسلم 2042
47۔ روزہ افطار کروانے والے کے لیے دعا
أَفْطَرَ عِنْدَكُمُ الصَّائِمُونَ، وَأَكَلَ طَعَامَكُمُ الْأَبْرَارُ، وَصَلَّتْ عَلَيْكُمُ الْمَلَائِكَةُ
ترجمہ: تمہارے ہاں روزہ دار افطار کرتے رہیں، نیک لوگ تمہارا کھانا کھاتے رہیں، اور فرشتے تمہارے لیے رحمت کی دعا کرتے رہیں۔
حوالہ: سنن ابو داود 3854، سنن ابن ماجہ 1747
48۔ افطار کے وقت کی دعا
ذَهَبَ الظَّمَأُ وَابْتَلَّتِ الْعُرُوقُ وَثَبَتَ الْأَجْرُ إِنْ شَاءَ اللَّهُ
ترجمہ: پیاس چلی گئی، رگیں تر ہو گئیں اور ان شاء اللہ اجر پکا ہو گیا۔
حوالہ: سنن ابو داود 2357
49۔ کھلانے پلانے والے کے لیے دعا
اللَّهُمَّ أَطْعِمْ مَنْ أَطْعَمَنِي، وَاسْقِ مَنْ سَقَانِي
ترجمہ: اے اللہ! جس نے مجھے کھلایا اسے کھلا، اور جس نے مجھے پلایا اسے پلا۔
حوالہ: صحیح مسلم 2055
50۔ دودھ پینے کے بعد کی دعا
اللَّهُمَّ بَارِكْ لَنَا فِيهِ وَزِدْنَا مِنْهُ
ترجمہ: اے اللہ! ہمیں اس میں برکت دے اور ہمیں اس سے مزید عطا فرما۔ (دودھ کے علاوہ کھانے کے بعد: «وَأَطْعِمْنَا خَيْرًا مِنْهُ» یعنی اس سے بہتر کھانا عطا فرما۔)
حوالہ: سنن ابو داود 3730، سنن ترمذی 3455
51۔ نکاح پر مبارک باد کی دعا
بَارَكَ اللَّهُ لَكَ، وَبَارَكَ عَلَيْكَ، وَجَمَعَ بَيْنَكُمَا فِي خَيْرٍ
ترجمہ: اللہ تمہیں برکت دے، تم پر برکت نازل کرے اور تم دونوں کو خیر میں جمع رکھے۔
حوالہ: سنن ابو داود 2130، سنن ترمذی 1091
52۔ نئی دلہن کی بھلائی کی دعا
اللَّهُمَّ إِنِّي أَسْأَلُكَ خَيْرَهَا وَخَيْرَ مَا جَبَلْتَهَا عَلَيْهِ، وَأَعُوذُ بِكَ مِنْ شَرِّهَا وَشَرِّ مَا جَبَلْتَهَا عَلَيْهِ
ترجمہ: اے اللہ! میں تجھ سے اس کی بھلائی اور اس کی فطرت میں رکھی ہوئی بھلائی مانگتا ہوں، اور اس کے شر اور اس کی فطرت میں رکھے ہوئے شر سے تیری پناہ مانگتا ہوں۔
حوالہ: سنن ابو داود 2160، سنن ابن ماجہ 1918
53۔ شیطان کے شر سے اولاد کی حفاظت کی دعا
بِسْمِ اللَّهِ، اللَّهُمَّ جَنِّبْنَا الشَّيْطَانَ وَجَنِّبِ الشَّيْطَانَ مَا رَزَقْتَنَا
ترجمہ: اللہ کے نام سے، اے اللہ! ہمیں شیطان سے بچا اور جو (اولاد) تو ہمیں دے اسے بھی شیطان سے بچا۔
حوالہ: صحیح بخاری 141، صحیح مسلم 1434
54۔ مریض کے لیے مکمل شفا کی دعا
اللَّهُمَّ رَبَّ النَّاسِ، أَذْهِبِ الْبَاسَ، اشْفِهِ وَأَنْتَ الشَّافِي، لَا شِفَاءَ إِلَّا شِفَاؤُكَ، شِفَاءً لَا يُغَادِرُ سَقَمًا
ترجمہ: اے اللہ! لوگوں کے رب! تکلیف دور کر دے، شفا دے، تو ہی شفا دینے والا ہے، تیری شفا کے سوا کوئی شفا نہیں، ایسی شفا دے جو کوئی بیماری باقی نہ چھوڑے۔
حوالہ: صحیح بخاری 5675، صحیح مسلم 2191
55۔ عیادت کے وقت سات بار پڑھنے کی دعا
أَسْأَلُ اللَّهَ الْعَظِيمَ رَبَّ الْعَرْشِ الْعَظِيمِ أَنْ يَشْفِيَكَ
ترجمہ: میں عظمت والے اللہ، عرشِ عظیم کے رب سے سوال کرتا ہوں کہ وہ تمہیں شفا دے۔ (سات بار)
حوالہ: سنن ابو داود 3106، سنن ترمذی 2083
56۔ بیمار پر دم کی دعا
بِسْمِ اللَّهِ أَرْقِيكَ، مِنْ كُلِّ شَيْءٍ يُؤْذِيكَ، مِنْ شَرِّ كُلِّ نَفْسٍ أَوْ عَيْنِ حَاسِدٍ، اللَّهُ يَشْفِيكَ، بِسْمِ اللَّهِ أَرْقِيكَ
ترجمہ: اللہ کے نام سے میں تم پر دم کرتا ہوں، ہر اس چیز سے جو تمہیں تکلیف دے، ہر جان کے شر اور حسد کرنے والی نظر سے۔ اللہ تمہیں شفا دے، اللہ کے نام سے میں تم پر دم کرتا ہوں۔
حوالہ: صحیح مسلم 2186
57۔ درد کی جگہ ہاتھ رکھ کر پڑھنے کی دعا
أَعُوذُ بِعِزَّةِ اللَّهِ وَقُدْرَتِهِ مِنْ شَرِّ مَا أَجِدُ وَأُحَاذِرُ
ترجمہ: میں اللہ کی عزت و قدرت کی پناہ لیتا ہوں اس تکلیف کے شر سے جو میں محسوس کرتا ہوں اور جس کا مجھے ڈر ہے۔ (درد کی جگہ ہاتھ رکھ کر، پہلے تین بار بسم اللہ اور پھر یہ دعا سات بار)
حوالہ: صحیح مسلم 2202
58۔ سفر میں کسی جگہ ٹھہرتے وقت کی دعا
أَعُوذُ بِكَلِمَاتِ اللَّهِ التَّامَّاتِ مِنْ شَرِّ مَا خَلَقَ
ترجمہ: میں اللہ کے مکمل کلمات کی پناہ لیتا ہوں اس کی ہر مخلوق کے شر سے۔
حوالہ: صحیح مسلم 2709
59۔ بچوں کی حفاظت کے لیے دم کی دعا
أُعِيذُكُمَا بِكَلِمَاتِ اللَّهِ التَّامَّةِ مِنْ كُلِّ شَيْطَانٍ وَهَامَّةٍ، وَمِنْ كُلِّ عَيْنٍ لَامَّةٍ
ترجمہ: میں تم دونوں کو اللہ کے مکمل کلمات کی پناہ میں دیتا ہوں، ہر شیطان، ہر زہریلے جانور اور ہر نقصان پہنچانے والی نظر سے۔
حوالہ: صحیح بخاری 3371
60۔ کان، آنکھ، زبان، دل اور شہوت کے شر سے پناہ
اللَّهُمَّ إِنِّي أَعُوذُ بِكَ مِنْ شَرِّ سَمْعِي، وَمِنْ شَرِّ بَصَرِي، وَمِنْ شَرِّ لِسَانِي، وَمِنْ شَرِّ قَلْبِي، وَمِنْ شَرِّ مَنِيِّي
ترجمہ: اے اللہ! میں اپنے کان، اپنی آنکھ، اپنی زبان، اپنے دل اور اپنی شرم گاہ (کی خواہش) کے شر سے تیری پناہ مانگتا ہوں۔
حوالہ: سنن ابو داود 1551، سنن ترمذی 3492، سنن نسائی 5444
حصہ سوم (61 تا 90)
61۔ سب سے افضل استغفار (سید الاستغفار)
اللَّهُمَّ أَنْتَ رَبِّي لَا إِلَهَ إِلَّا أَنْتَ، خَلَقْتَنِي وَأَنَا عَبْدُكَ، وَأَنَا عَلَى عَهْدِكَ وَوَعْدِكَ مَا اسْتَطَعْتُ، أَعُوذُ بِكَ مِنْ شَرِّ مَا صَنَعْتُ، أَبُوءُ لَكَ بِنِعْمَتِكَ عَلَيَّ، وَأَبُوءُ بِذَنْبِي فَاغْفِرْ لِي، فَإِنَّهُ لَا يَغْفِرُ الذُّنُوبَ إِلَّا أَنْتَ
ترجمہ: اے اللہ! تو میرا رب ہے، تیرے سوا کوئی معبود نہیں، تو نے مجھے پیدا کیا اور میں تیرا بندہ ہوں، اور جہاں تک مجھ سے ہو سکے تیرے عہد اور وعدے پر قائم ہوں۔ میں اپنے کیے کے شر سے تیری پناہ مانگتا ہوں، مجھ پر تیری نعمتوں کا اقرار کرتا ہوں اور اپنے گناہ کا بھی اقرار کرتا ہوں، پس مجھے بخش دے، کیونکہ تیرے سوا کوئی گناہ نہیں بخشتا۔
حوالہ: صحیح بخاری 6306
62۔ غم، فکر، کاہلی، بزدلی اور قرض کے بوجھ سے پناہ
اللَّهُمَّ إِنِّي أَعُوذُ بِكَ مِنَ الْهَمِّ وَالْحَزَنِ، وَالْعَجْزِ وَالْكَسَلِ، وَالْبُخْلِ وَالْجُبْنِ، وَضَلَعِ الدَّيْنِ وَغَلَبَةِ الرِّجَالِ
ترجمہ: اے اللہ! میں فکر اور غم، بے بسی اور سستی، کنجوسی اور بزدلی، قرض کے بوجھ اور لوگوں کے غلبے سے تیری پناہ مانگتا ہوں۔
حوالہ: صحیح بخاری 6369
63۔ قرآن کو دل کی بہار اور غم کا علاج بنانے کی دعا
اللَّهُمَّ إِنِّي عَبْدُكَ، ابْنُ عَبْدِكَ، ابْنُ أَمَتِكَ، نَاصِيَتِي بِيَدِكَ، مَاضٍ فِيَّ حُكْمُكَ، عَدْلٌ فِيَّ قَضَاؤُكَ، أَسْأَلُكَ بِكُلِّ اسْمٍ هُوَ لَكَ، سَمَّيْتَ بِهِ نَفْسَكَ، أَوْ أَنْزَلْتَهُ فِي كِتَابِكَ، أَوْ عَلَّمْتَهُ أَحَدًا مِنْ خَلْقِكَ، أَوِ اسْتَأْثَرْتَ بِهِ فِي عِلْمِ الْغَيْبِ عِنْدَكَ، أَنْ تَجْعَلَ الْقُرْآنَ رَبِيعَ قَلْبِي، وَنُورَ صَدْرِي، وَجَلَاءَ حُزْنِي، وَذَهَابَ هَمِّي
ترجمہ: اے اللہ! میں تیرا بندہ ہوں، تیرے بندے اور تیری بندی کا بیٹا ہوں، میری پیشانی تیرے ہاتھ میں ہے، مجھ میں تیرا حکم چلتا ہے اور میرے بارے میں تیرا فیصلہ عدل ہے۔ میں تجھ سے تیرے ہر اس نام کے وسیلے سے مانگتا ہوں جو تو نے اپنا رکھا، یا اپنی کتاب میں اتارا، یا اپنی مخلوق میں سے کسی کو سکھایا، یا اپنے علمِ غیب میں اپنے پاس رکھا، کہ تو قرآن کو میرے دل کی بہار، میرے سینے کا نور، میرے غم کو دور کرنے والا اور میری فکر کو ختم کرنے والا بنا دے۔
حوالہ: مسند احمد 3704؛ السلسلہ الصحیحہ 199
64۔ پریشانی اور بے چینی کے وقت کی دعا
لَا إِلَهَ إِلَّا اللَّهُ الْعَظِيمُ الْحَلِيمُ، لَا إِلَهَ إِلَّا اللَّهُ رَبُّ الْعَرْشِ الْعَظِيمِ، لَا إِلَهَ إِلَّا اللَّهُ رَبُّ السَّمَاوَاتِ وَرَبُّ الْأَرْضِ وَرَبُّ الْعَرْشِ الْكَرِيمِ
ترجمہ: اللہ کے سوا کوئی معبود نہیں، وہ عظمت والا اور بردبار ہے۔ اللہ کے سوا کوئی معبود نہیں، وہ عرشِ عظیم کا رب ہے۔ اللہ کے سوا کوئی معبود نہیں، وہ آسمانوں کا رب، زمین کا رب اور عرشِ کریم کا رب ہے۔
حوالہ: صحیح بخاری 6346، صحیح مسلم 2730
65۔ فریاد اور مدد کی دعا
يَا حَيُّ يَا قَيُّومُ بِرَحْمَتِكَ أَسْتَغِيثُ
ترجمہ: اے زندہ! اے سب کو سنبھالنے والے! میں تیری رحمت کے وسیلے سے فریاد کرتا ہوں۔
حوالہ: سنن ترمذی 3524
66۔ اللہ پر بھروسے کا کلمہ
حَسْبُنَا اللَّهُ وَنِعْمَ الْوَكِيلُ
ترجمہ: ہمیں اللہ کافی ہے اور وہ بہترین کارساز ہے۔
حوالہ: صحیح بخاری 4563
67۔ اپنے کیے اور نہ کیے ہوئے عمل کے شر سے پناہ
اللَّهُمَّ إِنِّي أَعُوذُ بِكَ مِنْ شَرِّ مَا عَمِلْتُ، وَمِنْ شَرِّ مَا لَمْ أَعْمَلْ
ترجمہ: اے اللہ! میں اس برائی سے تیری پناہ مانگتا ہوں جو میں نے کی، اور اس سے بھی جو میں نے نہیں کی۔
حوالہ: صحیح مسلم 2716
68۔ سوتے وقت کی مختصر دعا
بِاسْمِكَ اللَّهُمَّ أَمُوتُ وَأَحْيَا
ترجمہ: اے اللہ! تیرے ہی نام سے میں مرتا (سوتا) ہوں اور جیتا (جاگتا) ہوں۔
حوالہ: صحیح بخاری 6324
69۔ اللہ کے سپرد ہو جانے کی دعا (سونے سے پہلے)
اللَّهُمَّ أَسْلَمْتُ نَفْسِي إِلَيْكَ، وَفَوَّضْتُ أَمْرِي إِلَيْكَ، وَوَجَّهْتُ وَجْهِي إِلَيْكَ، وَأَلْجَأْتُ ظَهْرِي إِلَيْكَ، رَغْبَةً وَرَهْبَةً إِلَيْكَ، لَا مَلْجَأَ وَلَا مَنْجَا مِنْكَ إِلَّا إِلَيْكَ، آمَنْتُ بِكِتَابِكَ الَّذِي أَنْزَلْتَ، وَبِنَبِيِّكَ الَّذِي أَرْسَلْتَ
ترجمہ: اے اللہ! میں نے اپنی جان تیرے سپرد کر دی، اپنا معاملہ تجھے سونپ دیا، اپنا رخ تیری طرف کر لیا اور اپنی پشت تیرے سہارے پر رکھ دی، تیری امید اور تیرے خوف کے ساتھ۔ تجھ سے بچ کر کہیں پناہ اور نجات نہیں مگر تیری ہی طرف۔ میں تیری اس کتاب پر ایمان لایا جو تو نے اتاری اور تیرے اس نبی پر جسے تو نے بھیجا۔
حوالہ: صحیح بخاری 247، صحیح مسلم 2710
70۔ قیامت کے دن عذاب سے بچاؤ کی دعا
اللَّهُمَّ قِنِي عَذَابَكَ يَوْمَ تَبْعَثُ عِبَادَكَ
ترجمہ: اے اللہ! مجھے اپنے عذاب سے بچا لینا اس دن جب تو اپنے بندوں کو دوبارہ اٹھائے گا۔
حوالہ: سنن ابو داود 5045، سنن ترمذی 3398
71۔ کھلانے، پلانے، کفایت اور ٹھکانہ دینے پر شکر
الْحَمْدُ لِلَّهِ الَّذِي أَطْعَمَنَا وَسَقَانَا، وَكَفَانَا وَآوَانَا، فَكَمْ مِمَّنْ لَا كَافِيَ لَهُ وَلَا مُؤْوِيَ
ترجمہ: تمام تعریف اس اللہ کے لیے ہے جس نے ہمیں کھلایا، پلایا، ہماری کفایت کی اور ہمیں ٹھکانہ دیا۔ کتنے ہی لوگ ہیں جن کا نہ کوئی کفایت کرنے والا ہے نہ ٹھکانہ دینے والا۔
حوالہ: صحیح مسلم 2715
72۔ رات کو آنکھ کھلنے پر کی دعا
لَا إِلَهَ إِلَّا اللَّهُ وَحْدَهُ لَا شَرِيكَ لَهُ، لَهُ الْمُلْكُ وَلَهُ الْحَمْدُ وَهُوَ عَلَى كُلِّ شَيْءٍ قَدِيرٌ، الْحَمْدُ لِلَّهِ وَسُبْحَانَ اللَّهِ وَلَا إِلَهَ إِلَّا اللَّهُ وَاللَّهُ أَكْبَرُ وَلَا حَوْلَ وَلَا قُوَّةَ إِلَّا بِاللَّهِ، اللَّهُمَّ اغْفِرْ لِي
ترجمہ: اللہ کے سوا کوئی معبود نہیں، وہ اکیلا ہے، اس کا کوئی شریک نہیں، بادشاہی اور تعریف اسی کی ہے اور وہ ہر چیز پر قادر ہے۔ تعریف اللہ کے لیے ہے، اللہ پاک ہے، اس کے سوا کوئی معبود نہیں، اللہ سب سے بڑا ہے، اور گناہ سے بچنے اور نیکی کرنے کی طاقت صرف اللہ ہی سے ہے۔ اے اللہ! مجھے بخش دے۔
حوالہ: صحیح بخاری 1154
73۔ وتر میں ہدایت و حفاظت کی دعا (دعائے قنوت)
اللَّهُمَّ اهْدِنِي فِيمَنْ هَدَيْتَ، وَعَافِنِي فِيمَنْ عَافَيْتَ، وَتَوَلَّنِي فِيمَنْ تَوَلَّيْتَ، وَبَارِكْ لِي فِيمَا أَعْطَيْتَ، وَقِنِي شَرَّ مَا قَضَيْتَ، فَإِنَّكَ تَقْضِي وَلَا يُقْضَى عَلَيْكَ، وَإِنَّهُ لَا يَذِلُّ مَنْ وَالَيْتَ، تَبَارَكْتَ رَبَّنَا وَتَعَالَيْتَ
ترجمہ: اے اللہ! جنہیں تو نے ہدایت دی ان میں مجھے بھی ہدایت دے، جنہیں عافیت دی ان میں مجھے بھی عافیت دے، جن کا تو والی بنا ان میں میرا بھی والی بن جا، جو تو نے عطا کیا اس میں برکت دے، اور اپنے فیصلے کی برائی سے مجھے بچا، کیونکہ تو فیصلہ کرتا ہے اور تجھ پر کوئی فیصلہ نہیں چل سکتا، اور جسے تو دوست بنا لے وہ ذلیل نہیں ہوتا۔ اے ہمارے رب! تو برکت والا اور بلند ہے۔
حوالہ: سنن ابو داود 1425، سنن ترمذی 464، سنن نسائی 1745
74۔ شبِ قدر کی دعا
اللَّهُمَّ إِنَّكَ عَفُوٌّ تُحِبُّ الْعَفْوَ فَاعْفُ عَنِّي
ترجمہ: اے اللہ! تو بہت معاف کرنے والا ہے، معافی کو پسند کرتا ہے، پس مجھے معاف فرما دے۔
حوالہ: سنن ترمذی 3513، سنن ابن ماجہ 3850
75۔ بارش دیکھ کر کی دعا
اللَّهُمَّ صَيِّبًا نَافِعًا
ترجمہ: اے اللہ! اسے نفع دینے والی بارش بنا دے۔
حوالہ: صحیح بخاری 1032
76۔ بارش زیادہ ہو جائے تو یہ دعا
اللَّهُمَّ حَوَالَيْنَا وَلَا عَلَيْنَا
ترجمہ: اے اللہ! ہمارے اردگرد برسا اور ہم پر نہ برسا۔
حوالہ: صحیح بخاری 1014، صحیح مسلم 897
77۔ بارش مانگنے کی دعا (استسقاء)
اللَّهُمَّ اسْقِنَا غَيْثًا مُغِيثًا مَرِيئًا مَرِيعًا نَافِعًا غَيْرَ ضَارٍّ، عَاجِلًا غَيْرَ آجِلٍ
ترجمہ: اے اللہ! ہمیں ایسی بارش عطا فرما جو فریاد رسی کرے، خوشگوار ہو، سبزہ اگائے، نفع دے، نقصان نہ دے، جلد آئے اور دیر نہ کرے۔
حوالہ: سنن ابو داود 1169
78۔ تیز ہوا چلنے پر کی دعا
اللَّهُمَّ إِنِّي أَسْأَلُكَ خَيْرَهَا، وَخَيْرَ مَا فِيهَا، وَخَيْرَ مَا أُرْسِلَتْ بِهِ، وَأَعُوذُ بِكَ مِنْ شَرِّهَا، وَشَرِّ مَا فِيهَا، وَشَرِّ مَا أُرْسِلَتْ بِهِ
ترجمہ: اے اللہ! میں تجھ سے اس (ہوا) کی بھلائی، جو کچھ اس میں ہے اس کی بھلائی اور جس کام کے لیے یہ بھیجی گئی اس کی بھلائی مانگتا ہوں، اور اس کے شر، اس میں موجود شر اور جس مقصد کے لیے بھیجی گئی اس کے شر سے تیری پناہ مانگتا ہوں۔
حوالہ: صحیح مسلم 899
79۔ نیا چاند دیکھ کر کی دعا
اللَّهُمَّ أَهِلَّهُ عَلَيْنَا بِالْأَمْنِ وَالْإِيمَانِ، وَالسَّلَامَةِ وَالْإِسْلَامِ، رَبِّي وَرَبُّكَ اللَّهُ
ترجمہ: اے اللہ! اس چاند کو ہم پر امن و ایمان اور سلامتی و اسلام کے ساتھ طلوع فرما۔ (اے چاند!) میرا اور تیرا رب اللہ ہے۔
حوالہ: سنن ترمذی 3451
80۔ دشمن کے شر سے حفاظت کی دعا
اللَّهُمَّ إِنَّا نَجْعَلُكَ فِي نُحُورِهِمْ، وَنَعُوذُ بِكَ مِنْ شُرُورِهِمْ
ترجمہ: اے اللہ! ہم تجھے ان کے مقابل رکھتے ہیں اور ان کی برائیوں سے تیری پناہ مانگتے ہیں۔
حوالہ: سنن ابو داود 1537
81۔ ظالم دشمنوں کے مقابلے میں مدد کی دعا
اللَّهُمَّ مُنْزِلَ الْكِتَابِ، سَرِيعَ الْحِسَابِ، اهْزِمِ الْأَحْزَابَ، اللَّهُمَّ اهْزِمْهُمْ وَزَلْزِلْهُمْ
ترجمہ: اے اللہ! کتاب اتارنے والے، جلد حساب لینے والے! دشمن گروہوں کو شکست دے۔ اے اللہ! انہیں شکست دے اور ان کو ہلا ڈال۔
حوالہ: صحیح بخاری 2933، صحیح مسلم 1742
82۔ نمازِ جنازہ میں میت کے لیے جامع دعا
اللَّهُمَّ اغْفِرْ لَهُ وَارْحَمْهُ، وَعَافِهِ وَاعْفُ عَنْهُ، وَأَكْرِمْ نُزُلَهُ، وَوَسِّعْ مُدْخَلَهُ، وَاغْسِلْهُ بِالْمَاءِ وَالثَّلْجِ وَالْبَرَدِ، وَنَقِّهِ مِنَ الْخَطَايَا كَمَا نَقَّيْتَ الثَّوْبَ الْأَبْيَضَ مِنَ الدَّنَسِ
ترجمہ: اے اللہ! اسے بخش دے، اس پر رحم فرما، اسے عافیت دے اور معاف کر دے، اس کی مہمانی عزت والی بنا، اس کی قبر کشادہ کر دے، اسے پانی، برف اور اولوں سے دھو دے، اور گناہوں سے ایسا صاف کر دے جیسے سفید کپڑا میل سے صاف کیا جاتا ہے۔
حوالہ: صحیح مسلم 963
83۔ نمازِ جنازہ میں سب مسلمانوں کے لیے دعا
اللَّهُمَّ اغْفِرْ لِحَيِّنَا وَمَيِّتِنَا، وَشَاهِدِنَا وَغَائِبِنَا، وَصَغِيرِنَا وَكَبِيرِنَا، وَذَكَرِنَا وَأُنْثَانَا، اللَّهُمَّ مَنْ أَحْيَيْتَهُ مِنَّا فَأَحْيِهِ عَلَى الْإِسْلَامِ، وَمَنْ تَوَفَّيْتَهُ مِنَّا فَتَوَفَّهُ عَلَى الْإِيمَانِ
ترجمہ: اے اللہ! ہمارے زندوں اور مُردوں، حاضر اور غائب، چھوٹوں اور بڑوں، مردوں اور عورتوں کو بخش دے۔ اے اللہ! ہم میں سے جسے تو زندہ رکھے اسے اسلام پر زندہ رکھ، اور جسے وفات دے اسے ایمان پر وفات دے۔
حوالہ: سنن ابو داود 3201، سنن ترمذی 1024، سنن ابن ماجہ 1498
84۔ قبرستان جاتے وقت کی دعا
السَّلَامُ عَلَيْكُمْ أَهْلَ الدِّيَارِ مِنَ الْمُؤْمِنِينَ وَالْمُسْلِمِينَ، وَإِنَّا إِنْ شَاءَ اللَّهُ بِكُمْ لَلَاحِقُونَ، أَسْأَلُ اللَّهَ لَنَا وَلَكُمُ الْعَافِيَةَ
ترجمہ: اے مومن اور مسلمان بستی والو! تم پر سلامتی ہو، ان شاء اللہ ہم بھی تم سے آ ملنے والے ہیں۔ میں اللہ سے اپنے اور تمہارے لیے عافیت مانگتا ہوں۔
حوالہ: صحیح مسلم 975
85۔ غم زدہ خاندان سے تعزیت کے الفاظ
إِنَّ لِلَّهِ مَا أَخَذَ، وَلَهُ مَا أَعْطَى، وَكُلُّ شَيْءٍ عِنْدَهُ بِأَجَلٍ مُسَمًّى
ترجمہ: بے شک جو اللہ نے لے لیا وہ بھی اسی کا ہے اور جو دیا وہ بھی اسی کا ہے، اور ہر چیز اس کے ہاں ایک مقرر وقت کے ساتھ ہے۔
حوالہ: صحیح بخاری 1284، صحیح مسلم 923
86۔ مصیبت پہنچنے پر کی دعا
إِنَّا لِلَّهِ وَإِنَّا إِلَيْهِ رَاجِعُونَ، اللَّهُمَّ أْجُرْنِي فِي مُصِيبَتِي، وَأَخْلِفْ لِي خَيْرًا مِنْهَا
ترجمہ: ہم اللہ کے ہیں اور اسی کی طرف لوٹ کر جانے والے ہیں۔ اے اللہ! مجھے میری مصیبت میں اجر دے اور اس کے بدلے مجھے اس سے بہتر عطا فرما۔
حوالہ: صحیح مسلم 918
87۔ چھینک پر دعا دینے والے کو جواب
يَهْدِيكُمُ اللَّهُ وَيُصْلِحُ بَالَكُمْ
ترجمہ: اللہ تمہیں ہدایت دے اور تمہارا حال درست کر دے۔ (جب چھینکنے والا «الحمد للہ» کہے اور سننے والا «یرحمک اللہ» کہے تو چھینکنے والا یہ کہے۔)
حوالہ: صحیح بخاری 6224
88۔ کسی مصیبت زدہ کو دیکھ کر شکر کی دعا
الْحَمْدُ لِلَّهِ الَّذِي عَافَانِي مِمَّا ابْتَلَاكَ بِهِ، وَفَضَّلَنِي عَلَى كَثِيرٍ مِمَّنْ خَلَقَ تَفْضِيلًا
ترجمہ: تمام تعریف اس اللہ کے لیے ہے جس نے مجھے اس (مصیبت) سے بچا لیا جس میں تجھے ڈالا، اور مجھے اپنی بہت سی مخلوق پر فضیلت دی۔ (یہ دعا دل میں پڑھیں، مصیبت زدہ کو سنا کر نہیں۔)
حوالہ: سنن ترمذی 3431
89۔ بازار میں داخل ہوتے وقت کی دعا
لَا إِلَهَ إِلَّا اللَّهُ وَحْدَهُ لَا شَرِيكَ لَهُ، لَهُ الْمُلْكُ وَلَهُ الْحَمْدُ، يُحْيِي وَيُمِيتُ وَهُوَ حَيٌّ لَا يَمُوتُ، بِيَدِهِ الْخَيْرُ، وَهُوَ عَلَى كُلِّ شَيْءٍ قَدِيرٌ
ترجمہ: اللہ کے سوا کوئی معبود نہیں، وہ اکیلا ہے، اس کا کوئی شریک نہیں، بادشاہی اور تعریف اسی کی ہے، وہی زندگی دیتا اور موت دیتا ہے، وہ ہمیشہ زندہ ہے اسے موت نہیں، ہر بھلائی اسی کے ہاتھ میں ہے اور وہ ہر چیز پر قادر ہے۔
حوالہ: سنن ترمذی 3428، سنن ابن ماجہ 2235
90۔ سفر پر جانے والے کو رخصت کرنے کی دعا
أَسْتَوْدِعُ اللَّهَ دِينَكَ وَأَمَانَتَكَ وَخَوَاتِيمَ عَمَلِكَ
ترجمہ: میں تمہارا دین، تمہاری امانت اور تمہارے آخری اعمال اللہ کے سپرد کرتا ہوں۔
حوالہ: سنن ابو داود 2600، سنن ترمذی 3443
حصہ چہارم (91 تا 120)
91۔ مسافر کے لیے تقویٰ اور آسانی کی دعا
زَوَّدَكَ اللَّهُ التَّقْوَى، وَغَفَرَ ذَنْبَكَ، وَيَسَّرَ لَكَ الْخَيْرَ حَيْثُ مَا كُنْتَ
ترجمہ: اللہ تمہیں تقویٰ کا زادِ راہ دے، تمہارا گناہ بخش دے اور تم جہاں بھی رہو تمہارے لیے بھلائی آسان کر دے۔
حوالہ: سنن ترمذی 3444
92۔ احسان کرنے والے کا شکریہ ادا کرنے کی دعا
جَزَاكَ اللَّهُ خَيْرًا
ترجمہ: اللہ تمہیں بہترین بدلہ دے۔
حوالہ: سنن ترمذی 2035
93۔ قرض لوٹاتے وقت قرض دینے والے کے لیے دعا
بَارَكَ اللَّهُ لَكَ فِي أَهْلِكَ وَمَالِكَ، إِنَّمَا جَزَاءُ السَّلَفِ الْحَمْدُ وَالْأَدَاءُ
ترجمہ: اللہ تمہارے گھر والوں اور مال میں برکت دے۔ قرض کا بدلہ تو شکر گزاری اور ادائیگی ہی ہے۔
حوالہ: سنن نسائی 4683، سنن ابن ماجہ 2424
94۔ مسجد میں داخل ہوتے وقت شیطان سے پناہ
أَعُوذُ بِاللَّهِ الْعَظِيمِ، وَبِوَجْهِهِ الْكَرِيمِ، وَسُلْطَانِهِ الْقَدِيمِ، مِنَ الشَّيْطَانِ الرَّجِيمِ
ترجمہ: میں عظمت والے اللہ کی، اس کے کریم چہرے کی اور اس کی قدیم بادشاہی کی پناہ لیتا ہوں، مردود شیطان سے۔
حوالہ: سنن ابو داود 466
95۔ مسجد میں داخل ہوتے وقت رحمت کے دروازے کھلنے کی دعا
بِسْمِ اللَّهِ، وَالصَّلَاةُ وَالسَّلَامُ عَلَى رَسُولِ اللَّهِ، اللَّهُمَّ افْتَحْ لِي أَبْوَابَ رَحْمَتِكَ
ترجمہ: اللہ کے نام سے، اور اللہ کے رسول پر درود و سلام ہو۔ اے اللہ! میرے لیے اپنی رحمت کے دروازے کھول دے۔
حوالہ: سنن ابن ماجہ 771؛ صحیح مسلم 713 (دعا کا آخری حصہ)
96۔ سفر سے واپسی کی دعا
آيِبُونَ تَائِبُونَ عَابِدُونَ لِرَبِّنَا حَامِدُونَ
ترجمہ: ہم لوٹنے والے ہیں، توبہ کرنے والے ہیں، عبادت کرنے والے ہیں اور اپنے رب کی تعریف کرنے والے ہیں۔
حوالہ: صحیح مسلم 1342
97۔ نیکی مکمل ہونے پر شکر کی دعا
الْحَمْدُ لِلَّهِ الَّذِي بِنِعْمَتِهِ تَتِمُّ الصَّالِحَاتُ
ترجمہ: تمام تعریف اس اللہ کے لیے ہے جس کی نعمت سے نیک کام مکمل ہوتے ہیں۔
حوالہ: سنن ابن ماجہ 3803
98۔ غصہ آنے پر پڑھنے کی دعا
أَعُوذُ بِاللَّهِ مِنَ الشَّيْطَانِ الرَّجِيمِ
ترجمہ: میں مردود شیطان سے اللہ کی پناہ مانگتا ہوں۔
حوالہ: صحیح بخاری 6115، صحیح مسلم 2610
99۔ نماز کے بعد اللہ کی عطا اور روک کا اقرار
اللَّهُمَّ لَا مَانِعَ لِمَا أَعْطَيْتَ، وَلَا مُعْطِيَ لِمَا مَنَعْتَ، وَلَا يَنْفَعُ ذَا الْجَدِّ مِنْكَ الْجَدُّ
ترجمہ: اے اللہ! جو تو دے اسے کوئی روکنے والا نہیں، اور جو تو روک لے اسے کوئی دینے والا نہیں، اور کسی مال دار یا بڑے مرتبے والے کو اس کا مرتبہ تیرے مقابلے میں فائدہ نہیں دیتا۔
حوالہ: صحیح بخاری 844، صحیح مسلم 593
100۔ سلام پھیرنے کے بعد کی مختصر دعا
اللَّهُمَّ أَنْتَ السَّلَامُ، وَمِنْكَ السَّلَامُ، تَبَارَكْتَ يَا ذَا الْجَلَالِ وَالْإِكْرَامِ
ترجمہ: اے اللہ! تو سلامتی والا ہے، سلامتی تجھی سے ہے، اے عظمت اور احسان والے! تو برکت والا ہے۔
حوالہ: صحیح مسلم 591
101۔ جنت کا خزانہ
لَا حَوْلَ وَلَا قُوَّةَ إِلَّا بِاللَّهِ
ترجمہ: گناہ سے بچنے کی طاقت اور نیکی کرنے کی قوت صرف اللہ کی مدد سے ہے۔
حوالہ: صحیح بخاری 6384، صحیح مسلم 2704
102۔ زبان پر ہلکے اور میزان میں بھاری دو کلمے
سُبْحَانَ اللَّهِ وَبِحَمْدِهِ، سُبْحَانَ اللَّهِ الْعَظِيمِ
ترجمہ: اللہ پاک ہے اور اپنی تعریف کے ساتھ ہے، عظمت والا اللہ پاک ہے۔
حوالہ: صحیح بخاری 6406، صحیح مسلم 2694
103۔ تسبیح بے شمار گنتی کے ساتھ
سُبْحَانَ اللَّهِ وَبِحَمْدِهِ، عَدَدَ خَلْقِهِ، وَرِضَا نَفْسِهِ، وَزِنَةَ عَرْشِهِ، وَمِدَادَ كَلِمَاتِهِ
ترجمہ: اللہ پاک ہے اور اپنی تعریف کے ساتھ ہے، اس کی مخلوق کی گنتی کے برابر، اس کی رضا کے برابر، اس کے عرش کے وزن کے برابر اور اس کے کلمات کی سیاہی کے برابر۔
حوالہ: صحیح مسلم 2726
104۔ ہر گناہ کی بخشش کا استغفار
أَسْتَغْفِرُ اللَّهَ الَّذِي لَا إِلَهَ إِلَّا هُوَ الْحَيَّ الْقَيُّومَ وَأَتُوبُ إِلَيْهِ
ترجمہ: میں اللہ سے بخشش مانگتا ہوں جس کے سوا کوئی معبود نہیں، وہ زندہ اور سب کو قائم رکھنے والا ہے، اور میں اس کی طرف توبہ کرتا ہوں۔
حوالہ: سنن ابو داود 1517، سنن ترمذی 3577
105۔ توبہ کی قبولیت کی دعا
رَبِّ اغْفِرْ لِي وَتُبْ عَلَيَّ، إِنَّكَ أَنْتَ التَّوَّابُ الرَّحِيمُ
ترجمہ: اے میرے رب! مجھے بخش دے اور میری توبہ قبول فرما، بے شک تو ہی توبہ قبول کرنے والا، رحم کرنے والا ہے۔
حوالہ: سنن ابو داود 1516، سنن ترمذی 3434
106۔ نبی ﷺ پر درود (درودِ ابراہیمی)
اللَّهُمَّ صَلِّ عَلَى مُحَمَّدٍ وَعَلَى آلِ مُحَمَّدٍ، كَمَا صَلَّيْتَ عَلَى إِبْرَاهِيمَ وَعَلَى آلِ إِبْرَاهِيمَ، إِنَّكَ حَمِيدٌ مَجِيدٌ، اللَّهُمَّ بَارِكْ عَلَى مُحَمَّدٍ وَعَلَى آلِ مُحَمَّدٍ، كَمَا بَارَكْتَ عَلَى إِبْرَاهِيمَ وَعَلَى آلِ إِبْرَاهِيمَ، إِنَّكَ حَمِيدٌ مَجِيدٌ
ترجمہ: اے اللہ! محمد ﷺ اور آلِ محمد پر رحمت نازل فرما جیسے تو نے ابراہیم اور آلِ ابراہیم پر رحمت نازل فرمائی، بے شک تو تعریف والا، بزرگی والا ہے۔ اے اللہ! محمد ﷺ اور آلِ محمد پر برکت نازل فرما جیسے تو نے ابراہیم اور آلِ ابراہیم پر برکت نازل فرمائی، بے شک تو تعریف والا، بزرگی والا ہے۔
حوالہ: صحیح بخاری 3370
107۔ برا خواب دیکھ کر پناہ مانگنے کی دعا
أَعُوذُ بِاللَّهِ مِنْ شَرِّهَا
ترجمہ: میں اس (خواب) کے شر سے اللہ کی پناہ مانگتا ہوں۔ (بائیں طرف تین بار ہلکا سا تھوک دیں اور کروٹ بدل لیں، کسی کو خواب نہ سنائیں۔)
حوالہ: صحیح بخاری 6986، صحیح مسلم 2261
108۔ آخری وقت میں اعلیٰ رفاقت کی دعا
اللَّهُمَّ اغْفِرْ لِي وَارْحَمْنِي وَأَلْحِقْنِي بِالرَّفِيقِ الْأَعْلَى
ترجمہ: اے اللہ! مجھے بخش دے، مجھ پر رحم فرما اور مجھے بلند ترین رفیقوں (انبیاء و صالحین) کے ساتھ ملا دے۔
حوالہ: صحیح بخاری 5674، صحیح مسلم 2444
109۔ صبح کی جامع دعا (ملک اللہ کا)
أَصْبَحْنَا وَأَصْبَحَ الْمُلْكُ لِلَّهِ، وَالْحَمْدُ لِلَّهِ، لَا إِلَهَ إِلَّا اللَّهُ وَحْدَهُ لَا شَرِيكَ لَهُ، لَهُ الْمُلْكُ وَلَهُ الْحَمْدُ وَهُوَ عَلَى كُلِّ شَيْءٍ قَدِيرٌ، رَبِّ أَسْأَلُكَ خَيْرَ مَا فِي هَذَا الْيَوْمِ وَخَيْرَ مَا بَعْدَهُ، وَأَعُوذُ بِكَ مِنْ شَرِّ مَا فِي هَذَا الْيَوْمِ وَشَرِّ مَا بَعْدَهُ، رَبِّ أَعُوذُ بِكَ مِنَ الْكَسَلِ وَسُوءِ الْكِبَرِ، رَبِّ أَعُوذُ بِكَ مِنْ عَذَابٍ فِي النَّارِ وَعَذَابٍ فِي الْقَبْرِ
ترجمہ: ہم نے صبح کی اور اللہ کی بادشاہی نے صبح کی، تعریف اللہ کے لیے ہے، اللہ کے سوا کوئی معبود نہیں، وہ اکیلا ہے، اس کا کوئی شریک نہیں، بادشاہی اور تعریف اسی کی ہے اور وہ ہر چیز پر قادر ہے۔ اے میرے رب! میں تجھ سے اس دن کی بھلائی اور اس کے بعد کی بھلائی مانگتا ہوں، اور اس دن کے شر اور اس کے بعد کے شر سے تیری پناہ مانگتا ہوں۔ اے میرے رب! سستی اور بڑھاپے کی خرابی سے تیری پناہ مانگتا ہوں۔ اے میرے رب! جہنم کے عذاب اور قبر کے عذاب سے تیری پناہ مانگتا ہوں۔
حوالہ: صحیح مسلم 2723
110۔ صبح و شام اللہ ہی کے سہارے جینے کی دعا
اللَّهُمَّ بِكَ أَصْبَحْنَا، وَبِكَ أَمْسَيْنَا، وَبِكَ نَحْيَا، وَبِكَ نَمُوتُ، وَإِلَيْكَ النُّشُورُ
ترجمہ: اے اللہ! تیرے ہی (حکم اور مدد) سے ہم نے صبح کی، تیرے ہی سے شام کی، تیرے ہی سے جیتے ہیں اور تیرے ہی سے مرتے ہیں، اور تیری ہی طرف اٹھ کر جانا ہے۔
حوالہ: سنن ابو داود 5068، سنن ترمذی 3391
111۔ نفس اور شیطان کے شر اور شرک سے پناہ
اللَّهُمَّ عَالِمَ الْغَيْبِ وَالشَّهَادَةِ، فَاطِرَ السَّمَاوَاتِ وَالْأَرْضِ، رَبَّ كُلِّ شَيْءٍ وَمَلِيكَهُ، أَشْهَدُ أَنْ لَا إِلَهَ إِلَّا أَنْتَ، أَعُوذُ بِكَ مِنْ شَرِّ نَفْسِي، وَمِنْ شَرِّ الشَّيْطَانِ وَشِرْكِهِ
ترجمہ: اے اللہ! غیب اور ظاہر کے جاننے والے، آسمانوں اور زمین کو پیدا کرنے والے، ہر چیز کے رب اور مالک! میں گواہی دیتا ہوں کہ تیرے سوا کوئی معبود نہیں۔ میں اپنے نفس کے شر سے اور شیطان کے شر اور اس کے شرک (کی دعوت) سے تیری پناہ مانگتا ہوں۔
حوالہ: سنن ابو داود 5067، سنن ترمذی 3392
112۔ ہر نقصان سے حفاظت کی دعا (صبح و شام تین بار)
بِسْمِ اللَّهِ الَّذِي لَا يَضُرُّ مَعَ اسْمِهِ شَيْءٌ فِي الْأَرْضِ وَلَا فِي السَّمَاءِ وَهُوَ السَّمِيعُ الْعَلِيمُ
ترجمہ: اس اللہ کے نام سے جس کے نام کے ساتھ زمین و آسمان میں کوئی چیز نقصان نہیں پہنچا سکتی، اور وہ خوب سننے والا، خوب جاننے والا ہے۔
حوالہ: سنن ابو داود 5088، سنن ترمذی 3388
113۔ جنت واجب کرنے والا اقرار
رَضِيتُ بِاللَّهِ رَبًّا، وَبِالْإِسْلَامِ دِينًا، وَبِمُحَمَّدٍ نَبِيًّا
ترجمہ: میں اللہ کے رب ہونے، اسلام کے دین ہونے اور محمد ﷺ کے نبی ہونے پر راضی ہوں۔
حوالہ: سنن ابو داود 1529
114۔ نماز کی ابتدائی دعا (ثنا)
سُبْحَانَكَ اللَّهُمَّ وَبِحَمْدِكَ، وَتَبَارَكَ اسْمُكَ، وَتَعَالَى جَدُّكَ، وَلَا إِلَهَ غَيْرُكَ
ترجمہ: اے اللہ! تو پاک ہے اور اپنی تعریف کے ساتھ ہے، تیرا نام برکت والا ہے، تیری شان بلند ہے اور تیرے سوا کوئی معبود نہیں۔
حوالہ: سنن ابو داود 775، سنن ترمذی 242
115۔ نماز کی ابتدا میں اللہ کی بڑائی اور حمد
اللَّهُ أَكْبَرُ كَبِيرًا، وَالْحَمْدُ لِلَّهِ كَثِيرًا، وَسُبْحَانَ اللَّهِ بُكْرَةً وَأَصِيلًا
ترجمہ: اللہ سب سے بڑا ہے، بہت بڑا؛ تعریف اللہ کے لیے ہے، بہت زیادہ؛ اور اللہ صبح و شام پاک ہے۔
حوالہ: صحیح مسلم 601
116۔ رکوع کے بعد کی دعا
رَبَّنَا وَلَكَ الْحَمْدُ حَمْدًا كَثِيرًا طَيِّبًا مُبَارَكًا فِيهِ
ترجمہ: اے ہمارے رب! تعریف تیرے ہی لیے ہے، بہت زیادہ، پاکیزہ اور برکت والی تعریف۔
حوالہ: صحیح بخاری 799
117۔ نماز کا قعدہ (تشہد)
التَّحِيَّاتُ لِلَّهِ وَالصَّلَوَاتُ وَالطَّيِّبَاتُ، السَّلَامُ عَلَيْكَ أَيُّهَا النَّبِيُّ وَرَحْمَةُ اللَّهِ وَبَرَكَاتُهُ، السَّلَامُ عَلَيْنَا وَعَلَى عِبَادِ اللَّهِ الصَّالِحِينَ، أَشْهَدُ أَنْ لَا إِلَهَ إِلَّا اللَّهُ، وَأَشْهَدُ أَنَّ مُحَمَّدًا عَبْدُهُ وَرَسُولُهُ
ترجمہ: تمام زبانی، بدنی اور مالی عبادتیں اللہ ہی کے لیے ہیں۔ اے نبی! آپ پر سلام اور اللہ کی رحمت و برکتیں ہوں۔ ہم پر اور اللہ کے نیک بندوں پر سلام ہو۔ میں گواہی دیتا ہوں کہ اللہ کے سوا کوئی معبود نہیں، اور گواہی دیتا ہوں کہ محمد ﷺ اس کے بندے اور رسول ہیں۔
حوالہ: صحیح بخاری 831، صحیح مسلم 402
118۔ تشہد کے بعد چار چیزوں سے پناہ
اللَّهُمَّ إِنِّي أَعُوذُ بِكَ مِنْ عَذَابِ جَهَنَّمَ، وَمِنْ عَذَابِ الْقَبْرِ، وَمِنْ فِتْنَةِ الْمَحْيَا وَالْمَمَاتِ، وَمِنْ شَرِّ فِتْنَةِ الْمَسِيحِ الدَّجَّالِ
ترجمہ: اے اللہ! میں جہنم کے عذاب سے، قبر کے عذاب سے، زندگی اور موت کے فتنوں سے اور مسیح دجال کے فتنے کے شر سے تیری پناہ مانگتا ہوں۔
حوالہ: صحیح مسلم 588
119۔ اپنے اوپر بہت زیادتی کے اعتراف کی دعا
اللَّهُمَّ إِنِّي ظَلَمْتُ نَفْسِي ظُلْمًا كَثِيرًا، وَلَا يَغْفِرُ الذُّنُوبَ إِلَّا أَنْتَ، فَاغْفِرْ لِي مَغْفِرَةً مِنْ عِنْدِكَ، وَارْحَمْنِي، إِنَّكَ أَنْتَ الْغَفُورُ الرَّحِيمُ
ترجمہ: اے اللہ! میں نے اپنی جان پر بہت زیادہ ظلم کیا، اور تیرے سوا کوئی گناہ نہیں بخشتا، پس اپنی طرف سے خاص بخشش کے ساتھ مجھے بخش دے اور مجھ پر رحم فرما، بے شک تو ہی بخشنے والا، رحم کرنے والا ہے۔

133۔ مدد، ہدایت اور شکر گزاری کی نہایت جامع دعا
رَبِّ أَعِنِّي وَلَا تُعِنْ عَلَيَّ، وَانْصُرْنِي وَلَا تَنْصُرْ عَلَيَّ، وَامْكُرْ لِي وَلَا تَمْكُرْ عَلَيَّ، وَاهْدِنِي وَيَسِّرِ الْهُدَى إِلَيَّ، وَانْصُرْنِي عَلَى مَنْ بَغَى عَلَيَّ، رَبِّ اجْعَلْنِي لَكَ شَكَّارًا، لَكَ ذَكَّارًا، لَكَ رَهَّابًا، لَكَ مِطْوَاعًا، إِلَيْكَ مُخْبِتًا، أَوْ مُنِيبًا، رَبِّ تَقَبَّلْ تَوْبَتِي، وَاغْسِلْ حَوْبَتِي، وَأَجِبْ دَعْوَتِي، وَثَبِّتْ حُجَّتِي، وَاهْدِ قَلْبِي، وَسَدِّدْ لِسَانِي، وَاسْلُلْ سَخِيمَةَ قَلْبِي
ترجمہ: اے میرے رب! میری مدد فرما اور میرے خلاف کسی کی مدد نہ کر، مجھے غلبہ دے اور میرے خلاف کسی کو غلبہ نہ دے، میرے حق میں تدبیر فرما اور میرے خلاف تدبیر نہ ہونے دے، مجھے ہدایت دے اور ہدایت کو میرے لیے آسان کر دے، اور جو مجھ پر زیادتی کرے اس کے مقابلے میں میری مدد کر۔ اے میرے رب! مجھے اپنا بہت شکر گزار، بہت ذکر کرنے والا، بہت ڈرنے والا، بہت فرماں بردار، اور عاجزی کے ساتھ تیری طرف رجوع کرنے والا بنا دے۔ اے میرے رب! میری توبہ قبول فرما، میرے گناہ دھو دے، میری دعا قبول فرما، میری دلیل کو مضبوط رکھ، میرے دل کو ہدایت دے، میری زبان کو درست رکھ اور میرے دل کی کدورت نکال دے۔

134۔ کان، آنکھ اور طاقت کے آخر تک باقی رہنے کی دعا

ترجمہ: میں حاضر ہوں، اے اللہ! میں حاضر ہوں، میں حاضر ہوں، تیرا کوئی شریک نہیں، میں حاضر ہوں۔ بے شک تمام تعریف اور نعمت تیری ہی ہے اور بادشاہی بھی، تیرا کوئی شریک نہیں۔
حوالہ: صحیح بخاری 1549، صحیح مسلم 1184
145۔ مصیبت اور تنگی سے نکلنے کی دعائے یونس

ترجمہ: تیرے سوا کوئی معبود نہیں، تو پاک ہے، بے شک میں ہی ظالموں میں سے تھا۔

146۔ صبح کو فطرتِ اسلام پر ہونے کا اقرار

ترجمہ: ہم نے فطرتِ اسلام پر، کلمۂ اخلاص پر، اپنے نبی محمد ﷺ کے دین پر اور اپنے باپ ابراہیم کی ملت پر صبح کی، جو یکسو مسلمان تھے اور مشرکوں میں سے نہ تھے۔

147۔ بُرے پڑوسی سے پناہ
اللَّهُمَّ إِنِّي أَعُوذُ بِكَ مِنْ جَارِ السُّوءِ فِي دَارِ الْمُقَامَةِ، فَإِنَّ جَارَ الْبَادِيَةِ يَتَحَوَّلُ
ترجمہ: اے اللہ! میں مستقل رہنے کی جگہ میں بُرے پڑوسی سے تیری پناہ مانگتا ہوں، کیونکہ صحرا کا پڑوسی تو (جلد) چلا جاتا ہے۔

148۔ میت کو قبر میں رکھتے وقت کی دعا

150۔ مرنے والے کی آنکھیں بند کرتے وقت کی دعا

حوالہ: صحیح مسلم 920

151۔ مدینہ کے پھلوں، پیمانوں اور شہر میں برکت کی دعا
اللَّهُمَّ بَارِكْ لَنَا فِي ثَمَرِنَا، وَبَارِكْ لَنَا فِي مَدِينَتِنَا، وَبَارِكْ لَنَا فِي صَاعِنَا، وَبَارِكْ لَنَا فِي مُدِّنَا
ترجمہ: اے اللہ! ہمارے پھلوں میں برکت دے، ہمارے شہر میں برکت دے، ہمارے صاع میں برکت دے اور ہمارے مُد (ناپنے کے پیمانوں) میں برکت دے۔
حوالہ: صحیح مسلم 1373
152۔ شام اور یمن کے لیے برکت کی دعا
اللَّهُمَّ بَارِكْ لَنَا فِي شَامِنَا، اللَّهُمَّ بَارِكْ لَنَا فِي يَمَنِنَا
ترجمہ: اے اللہ! ہمارے شام میں ہمیں برکت دے، اے اللہ! ہمارے یمن میں ہمیں برکت دے۔
حوالہ: صحیح بخاری 1037
153۔ آخرت کی زندگی کو اصل جاننے اور مہاجرین و انصار کی مغفرت کی دعا
اللَّهُمَّ لَا عَيْشَ إِلَّا عَيْشُ الْآخِرَةِ، فَاغْفِرْ لِلْأَنْصَارِ وَالْمُهَاجِرَةِ
ترجمہ: اے اللہ! اصل زندگی تو آخرت ہی کی زندگی ہے، پس انصار اور مہاجرین کو بخش دے۔
حوالہ: صحیح بخاری 2834، صحیح مسلم 1805
154۔ اللہ کی راہ میں شہادت اور مدینہ میں موت کی دعا
اللَّهُمَّ ارْزُقْنِي شَهَادَةً فِي سَبِيلِكَ، وَاجْعَلْ مَوْتِي فِي بَلَدِ رَسُولِكَ
ترجمہ: اے اللہ! مجھے اپنی راہ میں شہادت نصیب فرما اور میری موت اپنے رسول ﷺ کے شہر میں مقدر فرما۔
حوالہ: صحیح بخاری 1890
155۔ ظالموں کے مقابلے میں اللہ سے کفایت مانگنے کی دعا
اللَّهُمَّ اكْفِنِيهِمْ بِمَا شِئْتَ
ترجمہ: اے اللہ! تو جس طرح چاہے ان (ظالموں) کے مقابلے میں میری کفایت فرما۔
حوالہ: صحیح مسلم 3005
156۔ کروٹ لیتے وقت جان کی حفاظت کی دعا
بِاسْمِكَ رَبِّي وَضَعْتُ جَنْبِي، وَبِكَ أَرْفَعُهُ، فَإِنْ أَمْسَكْتَ نَفْسِي فَارْحَمْهَا، وَإِنْ أَرْسَلْتَهَا فَاحْفَظْهَا بِمَا تَحْفَظُ بِهِ عِبَادَكَ الصَّالِحِينَ
ترجمہ: اے میرے رب! تیرے نام سے میں نے اپنا پہلو (بستر پر) رکھا اور تیرے ہی نام سے اسے اٹھاؤں گا۔ اگر تو میری جان روک لے تو اس پر رحم فرما، اور اگر اسے چھوڑ دے تو اس کی ایسے حفاظت فرما جیسے تو اپنے نیک بندوں کی حفاظت کرتا ہے۔
حوالہ: صحیح بخاری 6320، صحیح مسلم 2714
157۔ اللہ ہی کو سہارا بنانے کی دعا
اللَّهُمَّ أَنْتَ عَضُدِي وَنَصِيرِي، بِكَ أَجُولُ وَبِكَ أَصُولُ وَبِكَ أُقَاتِلُ
ترجمہ: اے اللہ! تو میرا بازو اور میرا مددگار ہے، تیرے ہی سہارے میں تدبیر کرتا ہوں، تیرے ہی سہارے حملہ کرتا ہوں اور تیرے ہی سہارے لڑتا ہوں۔

158۔ قربانی کا جانور ذبح کرتے وقت کی دعا
بِسْمِ اللَّهِ، اللَّهُمَّ تَقَبَّلْ مِنْ مُحَمَّدٍ وَآلِ مُحَمَّدٍ وَمِنْ أُمَّةِ مُحَمَّدٍ
ترجمہ: اللہ کے نام سے، اے اللہ! محمد ﷺ، آلِ محمد اور امتِ محمد کی طرف سے قبول فرما۔

159۔ زکوٰۃ و صدقہ دینے والے کے لیے دعا
اللَّهُمَّ صَلِّ عَلَيْهِمْ

160۔ قبر کو بت نہ بننے دینے کی دعا

ترجمہ: اے اللہ! میری قبر کو ایسا بت نہ بنانا جس کی عبادت کی جائے۔
حوالہ: مسند احمد 7352
161۔ ایسے ایمان کی دعا جو کبھی نہ پلٹے
اللَّهُمَّ إِنِّي أَسْأَلُكَ إِيمَانًا لَا يَرْتَدُّ، وَنَعِيمًا لَا يَنْفَدُ، وَمُرَافَقَةَ النَّبِيِّ ﷺ فِي أَعْلَى جَنَّةِ الْخُلْدِ
ترجمہ: اے اللہ! میں تجھ سے ایسا ایمان مانگتا ہوں جو پلٹ نہ جائے، ایسی نعمت جو ختم نہ ہو، اور ہمیشہ کی جنت کے سب سے اونچے درجے میں نبی ﷺ کی رفاقت۔
حوالہ: مسند احمد؛ السلسلہ الصحیحہ (البانی: صحیح) — نمبر اپنی کاپی سے ملا لیں
162۔ رکوع میں اللہ کے سامنے مکمل خشوع کی دعا
اللَّهُمَّ لَكَ رَكَعْتُ، وَبِكَ آمَنْتُ، وَلَكَ أَسْلَمْتُ، خَشَعَ لَكَ سَمْعِي، وَبَصَرِي، وَمُخِّي، وَعَظْمِي، وَعَصَبِي
ترجمہ: اے اللہ! میں نے تیرے ہی لیے رکوع کیا، تجھ پر ایمان لایا اور تیرا ہی فرماں بردار ہوا۔ میرے کان، میری آنکھ، میرا مغز، میری ہڈیاں اور میرے پٹھے تیرے سامنے جھک گئے۔
حوالہ: صحیح مسلم 771
163۔ رکوع اور سجدے کی تسبیحات
سُبْحَانَ رَبِّيَ الْعَظِيمِ (رکوع میں)، سُبْحَانَ رَبِّيَ الْأَعْلَى (سجدے میں)
ترجمہ: میرا عظمت والا رب پاک ہے (رکوع میں)، میرا بلند و برتر رب پاک ہے (سجدے میں)۔
حوالہ: صحیح مسلم 772
164۔ رکوع سے اٹھنے کے بعد حمد کی وسعت والی دعا
رَبَّنَا لَكَ الْحَمْدُ، مِلْءَ السَّمَاوَاتِ وَمِلْءَ الْأَرْضِ، وَمِلْءَ مَا شِئْتَ مِنْ شَيْءٍ بَعْدُ
ترجمہ: اے ہمارے رب! تیرے ہی لیے تعریف ہے، آسمانوں کے بھر جانے کے برابر، زمین کے بھر جانے کے برابر، اور اس کے بعد جس چیز کے بھر جانے کے برابر تو چاہے۔
حوالہ: صحیح مسلم 476
165۔ سونے سے پہلے تسبیحِ فاطمہ

ترجمہ: اللہ پاک ہے، تمام تعریف اللہ کے لیے ہے، اللہ سب سے بڑا ہے۔ (حدیث کے مطابق یہ خادم سے بہتر ہے۔)
حوالہ: صحیح بخاری 3113، صحیح مسلم 2727
166۔ حکمرانوں اور ذمہ داروں کے لیے نبی ﷺ کی دعا (رحمت اور سختی کا بدلہ)
اللَّهُمَّ مَنْ وَلِيَ مِنْ أَمْرِ أُمَّتِي شَيْئًا فَشَقَّ عَلَيْهِمْ فَاشْقُقْ عَلَيْهِ، وَمَنْ وَلِيَ مِنْ أَمْرِ أُمَّتِي شَيْئًا فَرَفَقَ بِهِمْ فَارْفُقْ بِهِ

حوالہ: صحیح مسلم 1828
167۔ کسی کو تکلیف پہنچ جائے تو اس کے حق میں رحمت بنانے کی دعا
اللَّهُمَّ إِنِّي أَتَّخِذُ عِنْدَكَ عَهْدًا لَنْ تُخْلِفَنِيهِ، فَإِنَّمَا أَنَا بَشَرٌ، فَأَيُّ الْمُؤْمِنِينَ آذَيْتُهُ، أَوْ شَتَمْتُهُ، أَوْ جَلَدْتُهُ، أَوْ لَعَنْتُهُ، فَاجْعَلْهَا لَهُ صَلَاةً وَزَكَاةً وَقُرْبَةً تُقَرِّبُهُ بِهَا إِلَيْكَ يَوْمَ الْقِيَامَةِ
ترجمہ: اے اللہ! میں تجھ سے ایک وعدہ لیتا ہوں جس کی تو خلاف ورزی نہیں کرے گا، میں تو ایک انسان ہوں، پس جس مومن کو میں نے تکلیف دی، یا برا کہا، یا مارا، یا لعنت کی، تو اسے اس کے لیے رحمت، پاکیزگی اور ایسی قربت بنا دے جس کے ذریعے تو اسے قیامت کے دن اپنے قریب کر لے۔

168۔ بقیع کے مدفون مسلمانوں کے لیے مغفرت کی دعا

ترجمہ: اے اللہ! بقیعِ غرقد (مدینہ کے قبرستان) کے رہنے والوں کو بخش دے۔

169۔ حج و عمرہ میں سر منڈوانے اور بال کتروانے والوں کے لیے دعا

170۔ کسی کے لیے ثابت قدمی اور ہدایت یافتہ رہنما بننے کی دعا

حوالہ: سنن ابن ماجہ 3678
172۔ صبح کے وقت ہر نعمت پر شکر کی دعا
اللَّهُمَّ مَا أَصْبَحَ بِي مِنْ نِعْمَةٍ أَوْ بِأَحَدٍ مِنْ خَلْقِكَ فَمِنْكَ وَحْدَكَ لَا شَرِيكَ لَكَ، فَلَكَ الْحَمْدُ وَلَكَ الشُّكْرُ
ترجمہ: اے اللہ! جو نعمت آج صبح مجھے یا تیری مخلوق میں سے کسی کو ملی وہ تیری ہی طرف سے ہے، تو اکیلا ہے، تیرا کوئی شریک نہیں، پس تیرے ہی لیے تعریف ہے اور تیرے ہی لیے شکر ہے۔
